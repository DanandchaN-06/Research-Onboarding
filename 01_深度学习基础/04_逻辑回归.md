## 一、从回归到分类

### 1.1 分类问题的输出只有少数几个取值

**分类问题（classification）**，输出 $y$ 只取少数几个可能值中的一个。

### 1.2 二分类的命名约定

只有两个可能类别的任务叫**二分类（binary classification）**。课程里 class 与 category 交替使用，含义相同。
下表回答的是：两种常见记法分别叫什么类。

| **常见写法** | **所属类别** |
| --- | --- |
| no / false / 0 | 负类（negative class） |
| yes / true / 1 | 正类（positive class） |

### 1.3 线性回归直接套用会出问题

最自然的尝试是用已经学过的线性回归去拟合，得到一条直线 $f(x)$，再以 **0.5 为阈值**划分：

- 输出 $< 0.5$ → 预测 $y = 0$
- 输出 $\geq 0.5$ → 预测 $y = 1$

0.5 这条水平线与最佳拟合直线的交点，对应一条竖直分界线，也就是**决策边界（decision boundary）**：左侧预测 0，右侧预测 1。在这一组数据上，线性回归看起来给出了合理结果。

> ⚠️ **致命问题**：在右端更远处加入一个尺寸更大的样本后，这个样本本不该改变任何关于良恶性的判断结论，但重新拟合会让直线整体移动、**决策边界右移**，最终学到的是一个差得多的函数——尺寸大的肿瘤本该被判为恶性，却被分到了 0 一侧。

由此引出 **logistic regression（逻辑回归）**：它的输出落在 0 与 1 之间，能更好地拟合这类数据。它是当前最流行、使用最广泛的分类算法之一。

## 二、逻辑回归模型

### 2.1 需要拟合的是一条 S 形曲线

逻辑回归要拟合的不是直线，而是一条**S 形曲线**：形状平滑地抬升，两端分别贴近 0 和 1。

### 2.2 sigmoid 函数

先介绍核心构件：**sigmoid 函数**，也叫**逻辑函数（logistic function）**。
$g(z) = \frac{1}{1 + e^{-z}}$
$e$ 是数学常数，取值约 2.7；$e^{-z}$ 就是该常数取 $-z$ 次幂。
下表回答的是：z 取不同范围的值时，g(z) 的表现如何。

| z 的取值 | $e^{-z}$ | $g(z)$ |
| --- | --- | --- |
| 很大的正数（如 100） | 一个极小的数 | 接近 1 |
| 很大的负数 | 一个很大的数 | 接近 0 |
| $z = 0$ | $e^0 = 1$ | 0.5 |

这几种取值解释了曲线形状：从接近 0 起步，平滑增长到 1；当 $z = 0$ 时分母为 $1 + 1$，函数值正好落在 0.5。

> 💡 注意两张图的横轴不同：肿瘤大小的横轴都是正数，而 sigmoid 的自变量 $z$ **既可以取很大的正数，也可以取很大的负数**。

### 2.3 模型分两步搭起来

逻辑回归模型是一个**两步复合**：

#### 2.3.1 先算一个线性得分

把特征线性组合成一个得分，存进变量 $z$：
$z = \mathbf{w} \cdot \mathbf{x} + b$

#### 2.3.2 再把 $z$ 交给 sigmoid

把 $z$ 传进 sigmoid 函数 $g$，得到一个落在 0 到 1 之间的值。
两步合起来，就是逻辑回归模型：
$f_{\mathbf{w},b}(\mathbf{x}) = g(\mathbf{w} \cdot \mathbf{x} + b) = \frac{1}{1 + e^{-(\mathbf{w} \cdot \mathbf{x} + b)}}$
模型的输入是一个或一组特征 $\mathbf{x}$，输出是 0 到 1 之间的一个数。

### 2.4 输出的含义：属于正类的概率

逻辑回归的输出应当读作**概率**：在给定输入 $\mathbf{x}$ 的条件下，标签 $y = 1$ 的概率。
回到肿瘤例子，$\mathbf{x}$ 是肿瘤大小，$y$ 取 0 或 1。若某位患者的模型输出为 0.7，含义是**模型认为该肿瘤有 70% 的可能性是恶性**。

> 💡 $y$ 只能取 0 或 1，两种可能的概率相加等于 1。所以输出 0.7 时，$y = 0$ 的概率就是 **0.3（30%）**。这也是为什么输出值一定落在 0 到 1 之间。

论文或博客里常写成 $f_{\mathbf{w},b}(\mathbf{x}) = P(y = 1 \mid \mathbf{x}; \mathbf{w}, b)$：竖线表示「在给定特征 $\mathbf{x}$ 的条件下」，分号后的 $\mathbf{w}$ 和 $b$ 是影响该概率的参数。**这套记号不必记忆**，认识即可。

## 三、决策边界

### 3.1 从概率到 0/1 的预测规则

逻辑回归输出的是概率，要变成 0 或 1 的预测，需要一条划分标准。常见做法是取 **0.5 为阈值**：

- $f(\mathbf{x}) \geq 0.5$ → 预测 $y = 1$，记作 $\hat{y} = 1$
- $f(\mathbf{x}) < 0.5$ → 预测 $y = 0$，记作 $\hat{y} = 0$

### 3.2 0.5 阈值等价于 w·x + b ≥ 0

$f(\mathbf{x}) = g(z)$，所以「$f(\mathbf{x}) \geq 0.5$ 什么时候成立」等同于「$g(z) \geq 0.5$ 什么时候成立」。分两步化简：

- sigmoid 曲线在 $z = 0$ 处取 0.5，$z$ 落在轴的右半边的条件是 $z \geq 0$。
- 第二个条件：$z = \mathbf{w} \cdot \mathbf{x} + b$，所以条件就是 $\mathbf{w} \cdot \mathbf{x} + b \geq 0$。

$f_{\mathbf{w},b}(\mathbf{x}) \geq 0.5 \iff \mathbf{w} \cdot \mathbf{x} + b \geq 0$

> 💡 **结论**：模型在 $\mathbf{w} \cdot \mathbf{x} + b \geq 0$ 时预测 $y = 1$；在 $\mathbf{w} \cdot \mathbf{x} + b < 0$ 时预测 $y = 0$。中间的 sigmoid 被完全消掉了——**决策边界只由线性部分决定**。

### 3.3 两个特征：边界是一条直线

训练集有两个特征 $x_1$ 和 $x_2$，红色叉号是正例（$y = 1$），蓝色圆圈是负例（$y = 0$）。此时 $z$ 包含两项：
$z = w_1 x_1 + w_2 x_2 + b$
取一组具体参数 $w_1 = 1$、$w_2 = 1$、$b = -3$，则 $\mathbf{w} \cdot \mathbf{x} + b$ 变成 $x_1 + x_2 - 3$。划分预测结果就看 $z$ 在哪里等于 0：
$x_1 + x_2 - 3 = 0 \quad \Longrightarrow \quad x_1 + x_2 = 3$
这条线就是**决策边界**。在直线一侧（$x_1 + x_2 \geq 3$，图上右上方）模型预测 1，另一侧预测 0。**参数换成别的取值，决策边界也会跟着改变。**

### 3.4 多项式特征：边界可以变成圆

仿照线性回归的做法，把 $z$ 改成二次项的组合：
$z = w_1 x_1^2 + w_2 x_2^2 + b$
取 $w_1 = 1$、$w_2 = 1$、$b = -1$，则 $z = x_1^2 + x_2^2 - 1$。决策边界仍对应 $z = 0$：
$x_1^2 + x_2^2 = 1$
画在图上是一个**以原点为圆心、半径为 1 的圆**。圆外满足 $x_1^2 + x_2^2 \geq 1$，模型预测 $y = 1$；圆内满足 $x_1^2 + x_2^2 < 1$，模型预测 $y = 0$。

### 3.5 边界形状由放进去的特征决定

决策边界的形状取决于放进 $z$ 里的特征能有多复杂。
下表回答的是：特征复杂程度与可能的边界形状之间的关系。

| **放进去的特征** | **决策边界的形状** |
| --- | --- |
| 只有原始特征 $x_1, x_2, x_3$ | **永远是直线**（线性边界） |
| 加入平方项 $x_1^2, x_2^2$ | 圆、椭圆 |
| 加入更高次项与交叉项 $x_1 x_2$ 等 | 形状更复杂的曲线 |

> ⚠️ **只要特征里不含任何高阶项，逻辑回归的决策边界永远是线性的**。想让边界弯曲，必须像特征工程那样自己构造高阶项或交叉项。

## 四、逻辑回归的损失函数

### 4.1 成本函数要回答的问题

**成本函数（cost function）** 用来衡量一组具体参数与训练数据的拟合程度，有了这个度量，才有办法挑选更好的参数。
沿用前面的记号：

- $m$ —— 训练样本数量
- $n$ —— 特征个数，记作 $x_1$ 到 $x_n$
- $y$ —— 二分类标签，只取 0 或 1

本讲使用的模型为 $f(\mathbf{x}) = \dfrac{1}{1 + e^{-(\mathbf{w} \cdot \mathbf{x} + b)}}$，输出始终落在 0 与 1 之间。

### 4.2 平方误差为什么不能用

线性回归使用的成本函数是**凸函数（convex）**，形状像一只碗或一张吊床：梯度下降在这样的曲面上每一步都朝更低处走，最终收敛到全局最小值。
下表回答的是：同一个平方误差函数配上两种模型，结果有什么不同。

| **组合** | **函数形状** | **梯度下降的表现** |
| --- | --- | --- |
| 平方误差 + 线性回归 | 凸函数，只有一个最低点 | 可靠地收敛到全局最小值 |
| 平方误差 + 逻辑回归 | **非凸**，出现许多局部最小值 | 可能停在某个局部最小值，**不再保证抵达全局最优** |

$J(\mathbf{w}, b) = \frac{1}{m} \sum_{i=1}^{m} \frac{1}{2}\left(f(\mathbf{x}^{(i)}) - y^{(i)}\right)^2$
把 $f(\mathbf{x})$ 换成 $1/(1 + e^{-(\mathbf{w} \cdot \mathbf{x} + b)})$ 之后，同一个平方误差成本函数就变成非凸的。

> ⚠️ **凸性决定了梯度下降能不能可靠地找到全局最小值**。失去这一点，平方误差对逻辑回归来说就不是一个理想的成本函数。

### 4.3 把成本函数拆成单样本损失

构造新成本函数前，先对 $J(\mathbf{w}, b)$ 的定义做一点改动：盯住求和号里面那一项，称它为**单个训练样本上的损失（loss）**，用大写字母 $L$ 表示。
$L$ 是预测值 $f(\mathbf{x})$ 与真实标签 $y$ 的函数，记作 $L(f(\mathbf{x}), y)$，回答的是「模型在这一个样本上做得怎么样」。把所有样本的损失加起来取平均，就得到衡量整个训练集的成本函数：
$J(\mathbf{w}, b) = \frac{1}{m} \sum_{i=1}^{m} L\left(f(\mathbf{x}^{(i)}), y^{(i)}\right)$
平方误差只是其中一种取值：$L(f(\mathbf{x}), y) = \frac{1}{2}(f(\mathbf{x}) - y)^2$。接下来要做的，是换一种损失 $L$ 的形式，让整体成本函数保持凸性。

### 4.4 新损失：按真实标签分成两条分支

逻辑回归使用的损失按 $y$ 的取值分成两支：
$L(f(\mathbf{x}), y) = \begin{cases} -\log\left(f(\mathbf{x})\right) & \text{当 } y = 1 \\[4pt] -\log\left(1 - f(\mathbf{x})\right) & \text{当 } y = 0 \end{cases}$
因为 $f$ 始终落在 0 与 1 之间，两条曲线上只有 $f \in [0, 1]$ 这一段是相关的。
下表回答的是：两支损失分别惩罚什么、推动模型往哪走。

| **真实标签** | **损失** | **预测接近 1 时** | **预测接近 0 时** |
| --- | --- | --- | --- |
| $y = 1$ | $-\log f(\mathbf{x})$ | 损失趋近 0，**越接近 1 越好** | 损失急剧升高 |
| $y = 0$ | $-\log(1 - f(\mathbf{x}))$ | 损失急剧升高，**趋近无穷** | 损失趋近 0，**越接近 0 越好** |

逐点看 $y = 1$ 这一支：曲线在 $f = 1$ 处与横轴相交，损失为 0，往左则一路上升。

- 预测接近 1 —— 损失非常小，几乎为 0，因为预测已经很接近正确答案。
- 预测 0.5 —— 损失落在中间高度，不算高，但也没那么低。
- 预测 0.1 —— 模型只给出 10% 的概率而真实标签为 1，损失明显更高。

$y = 0$ 这一支与前一支镜像：$f$ 接近 0 时损失也接近 0，模型基本不受惩罚；$f$ 趋近 1 时损失趋于无穷。例如模型以 99.9% 的把握判断为恶性，而真实标签为 0，模型就要承担一个非常大的损失。

> 💡 **两条分支方向相反，惩罚的方向却一致**：预测 $f(\mathbf{x})$ 离真实值 $y$ 越远，损失越高；当预测几乎完全站在错误的一端时，损失急剧增大并趋于无穷。

### 4.5 整体成本函数是凸的

$J(\mathbf{w}, b) = \frac{1}{m} \sum_{i=1}^{m} L\left(f(\mathbf{x}^{(i)}), y^{(i)}\right)$
采用上面这组损失定义之后，**整体成本函数是凸函数**，因此可以可靠地用梯度下降走到全局最小值。（证明它是凸的超出本课程范围。）

## 五、损失函数的化简写法

### 5.1 为什么要把两支合并成一行

上一节的损失写成按 $y$ 取值分成两支的形式。本节把它合并成一行，好处在后面用梯度下降拟合参数时会体现出来——实现上更简单，不必再按 $y$ 分情况讨论。

### 5.2 一行式子覆盖两种情况

$L\left(f(\mathbf{x}), y\right) = -y \log\left(f(\mathbf{x})\right) - (1 - y)\log\left(1 - f(\mathbf{x})\right)$
这一行式子与分开写的两支**完全等价**。式中 $y$ 只能取 1 或 0，$f(\mathbf{x})$ 是模型输出。

### 5.3 代入 y 的两个取值验证

$y$ 只有 1 和 0 两种取值，代入后**总有一项的系数变成 0，那一项整项消失**，剩下的正好是定义里对应的那一支。
下表回答的是：$y$ 取两个值时，两项分别剩下什么。

| y 的取值 | 第一项 -y log(f) | 第二项 -(1-y) log(1-f) |
| --- | --- | --- |
| $y = 1$ | $-1 \cdot \log f$，即 $-\log f$ | 系数 $1 - y = 0$，整项为 0，直接去掉 |
| $y = 0$ | 系数 $y = 0$，整项为 0，直接去掉 | 系数 $1 - y = 1$，得到 $\log(1-f)$，取负后为 $-\log(1-f)$ |

两项相加的结果：$y = 1$ 时为 $-\log f$，$y = 0$ 时为 $-\log(1-f)$，**与分开写的两支一致**。由于 $y$ 只取 1 或 0，这个式子两种情况都成立，不需要再拆开。

### 5.4 化简后的成本函数

成本 $J$ 的定义没有变，仍是 $m$ 个样本损失的平均值：
$J = \frac{1}{m} \sum_{i=1}^{m} L$
代入上面的一行损失式子：
$J(\mathbf{w}, b) = \frac{1}{m} \sum_{i=1}^{m} \left[ -y^{(i)} \log\left(f(\mathbf{x}^{(i)})\right) - \left(1 - y^{(i)}\right)\log\left(1 - f(\mathbf{x}^{(i)})\right) \right]$
写成这个形式之后，拟合参数时不必再区分 $y$ 的两种取值，直接套用这一个式子即可。

> 💡 这个成本函数来自统计学中的**最大似然估计（maximum likelihood estimation）**。背后的推导不必深究，知道它有这样一个来历即可。

## 六、逻辑回归的梯度下降

### 6.1 训练目标

拟合逻辑回归的参数，就是找到一组 $\mathbf{w}$ 和 $b$，使成本函数 $J(\mathbf{w}, b)$ 取到最小值，办法是**梯度下降**。
参数定下来后模型即可投入使用：给定新输入 $\mathbf{x}$（例如一位新病人的检查数据），它能给出一次预测，或估计标签 $y = 1$ 的概率。

### 6.2 参数更新式

梯度下降反复更新每一个参数，写成逐个参数 $w_j$ 的形式：
$w_j := w_j - \alpha \frac{\partial J}{\partial w_j}$
$b := b - \alpha \frac{\partial J}{\partial b}$
$\alpha$ 是学习率，$\frac{\partial J}{\partial w_j}$ 和 $\frac{\partial J}{\partial b}$ 是成本函数对相应参数的偏导数。

### 6.3 两个偏导数的具体形式

先交代式子里用到的记号：
下表回答的是：公式里各个记号分别指什么。

| **记号** | **含义** |
| --- | --- |
| $m$ | 训练样本个数，求和下标 $i$ 从 1 取到 $m$ |
| $n$ | 特征个数，下标 $j$ 遍历这些特征 |
| $x_j^{(i)}$ | 第 $i$ 个训练样本的第 $j$ 个特征 |
| $f(\mathbf{x}^{(i)})$ | 模型对第 $i$ 个样本给出的预测值 |
| $y^{(i)}$ | 第 $i$ 个样本的真实标签 |

成本函数对 $w_j$ 的偏导数，是把每个样本上「预测值减去真实标签、再乘以该样本第 $j$ 个特征」的结果求和，最后取 $1/m$：
$\frac{\partial J}{\partial w_j} = \frac{1}{m} \sum_{i=1}^{m} \left( f(\mathbf{x}^{(i)}) - y^{(i)} \right) \cdot x_j^{(i)}$
对 $b$ 的偏导数与上面几乎一样，区别只在末尾不再乘以 $x_j^{(i)}$：
$\frac{\partial J}{\partial b} = \frac{1}{m} \sum_{i=1}^{m} \left( f(\mathbf{x}^{(i)}) - y^{(i)} \right)$

> ⚠️ 注意 $\frac{\partial J}{\partial w_j}$ 里的 $x_j^{(i)}$ **必须乘在求和号内部**，不能提到求和号外面——每个样本用的是它自己的第 $j$ 个特征值。

### 6.4 更新式相同 ≠ 同一个算法

把两个偏导数代回更新式，得到的表达式**和此前线性回归的梯度下降完全一样**，于是很容易冒出一个疑问：线性回归和逻辑回归是同一个算法吗？
下表回答的是：两者的差别究竟在哪里。

| **对照项** | **线性回归** | **逻辑回归** |
| --- | --- | --- |
| 预测函数 $f(\mathbf{x})$ | $\mathbf{w} \cdot \mathbf{x} + b$ | $\mathrm{sigmoid}(\mathbf{w} \cdot \mathbf{x} + b)$ |
| 更新式写法 | 与逻辑回归相同 | 与线性回归相同 |

> 💡 **更新式的写法确实一致，但两者是两个非常不同的算法**，区别来自 $f(\mathbf{x})$ 的定义：一个是线性函数，一个是把它再送进 sigmoid。这一点在推导时极易看混。

### 6.5 收敛检查与向量化

线性回归里用来监控梯度下降、确认已收敛的办法，**同样适用于逻辑回归**。和线性回归的向量化实现类似，逻辑回归的梯度下降也可以用向量化提速。

> 💡 配套实验里有一个「用 scikit-learn 训练逻辑回归」的演示，内容不长但很实用——它正是速查笔记里 `LogisticRegression` 那一节的实操来源。

## 七、速查表

### 7.1 核心公式

下表回答的是：逻辑回归从模型到更新式的全部关键公式。

| **名称** | **公式** |
| --- | --- |
| sigmoid 函数 | $g(z) = \dfrac{1}{1 + e^{-z}}$ |
| 逻辑回归模型 | $f_{\mathbf{w},b}(\mathbf{x}) = g(\mathbf{w} \cdot \mathbf{x} + b)$ |
| 预测规则 | $f \geq 0.5 \Rightarrow \hat{y} = 1$；$f < 0.5 \Rightarrow \hat{y} = 0$ |
| 决策边界条件 | $\mathbf{w} \cdot \mathbf{x} + b = 0$ |
| 损失（合并式） | $L = -y\log f - (1-y)\log(1-f)$ |
| 成本函数 | $J = \dfrac{1}{m}\sum_{i=1}^{m} L\left(f(\mathbf{x}^{(i)}), y^{(i)}\right)$ |
| 对 $w_j$ 的偏导 | $\dfrac{1}{m}\sum_{i=1}^{m}\left(f(\mathbf{x}^{(i)}) - y^{(i)}\right) x_j^{(i)}$ |
| 对 $b$ 的偏导 | $\dfrac{1}{m}\sum_{i=1}^{m}\left(f(\mathbf{x}^{(i)}) - y^{(i)}\right)$ |

### 7.2 与线性回归的对照

下表回答的是：两套算法在关键环节上的异同。

| **环节** | **线性回归** | **逻辑回归** |
| --- | --- | --- |
| 任务 | 回归（预测数值） | 分类（预测类别） |
| 模型输出 | 任意实数 | 0 到 1 之间的概率 |
| 成本函数 | 平方误差，凸函数 | 对数损失，凸函数 |
| 参数更新式 | 写法完全相同 | 写法完全相同 |
| 决策边界 | 不涉及 | 由 $\mathbf{w} \cdot \mathbf{x} + b = 0$ 决定，高阶特征可弯曲 |

### 7.3 易错点对照

下表回答的是：这一周最容易搞混的地方对应怎么理解。

| **易错点** | **正确理解** |
| --- | --- |
| 拿线性回归做分类 | 加入远端样本会让决策边界移动，结果不可靠 |
| 以为 positive class 就是「好的那一类」 | positive / negative 只表示 1 / 0，与好坏无关 |
| 输出 0.7 理解成「预测为 1」 | 是「属于 1 的**概率**为 70%」 |
| 以为决策边界由 sigmoid 决定 | sigmoid 被 0.5 阈值消掉，边界只由 $\mathbf{w} \cdot \mathbf{x} + b = 0$ 决定 |
| 用平方误差做逻辑回归 | 会变成非凸，梯度下降不保证全局最优，必须用对数损失 |
| 用原始特征却期望弯曲边界 | 不含高阶项时边界**永远是直线** |
| 以为逻辑回归和线性回归是同一个算法 | 更新式写法相同，但 $f(\mathbf{x})$ 定义不同，是两个算法 |

---

## 小结

> ✅ **一句话结论**：逻辑回归 = **线性得分 + sigmoid**，输出读作「$y=1$ 的概率」；以 0.5 为阈值可把预测规则化简成 $\mathbf{w} \cdot \mathbf{x} + b \geq 0$，而决策边界的形状完全由放进去的特征决定（原始特征只能给出直线）；训练时**必须换掉平方误差**（否则非凸），改用 $L = -y\log f - (1-y)\log(1-f)$，它使成本函数保持凸性；梯度下降的更新式与线性回归写法完全相同，但两者的 $f(\mathbf{x})$ 不同，因此是两个算法。
