# 05_正则化与过拟合

> 🧭 本页覆盖**吴恩达机器学习课程 P32–P36**。前半部分讲如何识别过拟合与欠拟合，后半部分讲正则化这一整套解决方案；内容续接 `04_逻辑回归`。

> ⚙️ **读前约定**：约定 $`m`$ 为样本数、$`n`$ 为特征数、$`\lambda`$ 为正则化参数。公式里的 $`f`$ 在线性回归中是 $`\mathbf{w}\cdot\mathbf{x} + b`$，在逻辑回归中是它再送入 sigmoid 后的输出。

## 一、什么是过拟合与欠拟合

### 1.1 两种失调

前面几讲的学习算法能完成不少任务，但训练过程中会碰到一类问题：**过拟合（overfitting）**；与之相邻的是**欠拟合（underfitting）**。二者是同一个病的两端——模型复杂度与数据不匹配。

> 🧭 本页主题是从「模型复杂度失调」到「正则化」这一条完整链条。下一讲要讲的 **正则化（regularization）** 就是对付过拟合最常用的技术，也是本页后半部分的主角。

### 1.2 房价回归中的三种拟合

回到房价预测：输入特征 $`x`$ 是房屋尺寸，预测值 $`y`$ 是房价。同一组数据用不同复杂度的函数去拟合，结果差别很大。
下表回答的是：三种复杂度的函数在同一份数据上分别得到什么结果。

| **拟合方式** | **训练数据上的表现** | **判断** |
| --- | --- | --- |
| 一次函数（直线） | 与数据走向不符，拟合得较差 | 欠拟合（underfit） |
| 二次函数（$`x`$ 与 $`x^2`$） | 贴合数据，新样本上的预测也合理 | 中间的「刚刚好」 |
| 四次多项式（$`x`$ 到 $`x^4`$） | 几乎完美穿过每个训练样本，训练误差为 0 | 过拟合（overfit） |

两端的病各有具体表现：

- **欠拟合的问题出在一个预设上**：算法认定数据是线性的，于是坚持去拟合一条直线，即使数据本身并非如此，最后得到的仍是一条拟合很差的直线。
- **过拟合的问题出在「太好了」**：把特征换成 $`x, x^2, x^3, x^4`$ 后，模型努力穿过每一个训练样本，训练集误差为 0。但曲线在尺寸较大的一段掉头向下，会预测**一套更大的房子比更小的房子还便宜**——对训练集拟合得几乎太好，好过了头。

### 1.3 高偏差与高方差

同样的两种失调，换一套术语就是**偏差（bias）**与**方差（variance）**。
下表回答的是：两种失调的术语对应与各自的内核。

| **失调** | **别名** | **内核** |
| --- | --- | --- |
| 欠拟合 | 高偏差（high bias） | 模型太简单，拟合能力不足以刻画数据 |
| 过拟合 | 高方差（high variance） | 模型太复杂，对训练数据过度敏感 |

> 💡 **高方差的直觉**：算法在极力贴合每一个训练样本，因此对数据非常敏感。假如训练集只变一点点——比如某套房子的价格稍高或稍低——拟合出的函数就可能完全变样。换一份数据去拟合同类高阶模型，得到的曲线也会明显不同，这正是「高方差」这个名称的由来。

中间那一档没有专门的名字，可以就叫 **just right（刚刚好）**，因为它既不是欠拟合也不是过拟合。机器学习的目标就是找到这样的模型；换成偏差和方差的说法，就是**既没有高偏差，也没有高方差**。

> 💡 课程用了一个童话式的比喻：桌上有三碗粥，一碗太冷、一碗太热，中间那碗温度居中，正好可以吃。欠拟合、过拟合与「刚刚好」的对应，和这三碗粥一样。

### 1.4 特征多少决定走向哪一端

失调的根源可以直接归结到特征数量上：
下表回答的是：特征数量与两种失调的对应关系。

| **特征情况** | **走向** |
| --- | --- |
| 特征太多 | 对训练集拟合过于好，过拟合、高方差 |
| 特征太少 | 欠拟合、高偏差 |

### 1.5 分类任务上的同一组对照

第二个例子是分类任务：决策边界是 $`z = 0`$ 的那条线，用来把正例与负例分开，模型还要照顾到新病人这类训练时没见过的样本。三种复杂度在这里重现，结论与房价回归完全一致。
下表回答的是：分类任务中三种决策边界的表现。

| **决策边界** | **结果** |
| --- | --- |
| 直线 | 欠拟合、高偏差。看上去不算太糟，但也不是对这份数据的好拟合 |
| 加上二次项 | 刚刚好。边界变成曲线，能比较好地泛化到新病人 |
| 高阶多项式 | 过拟合、高方差。模型极力扭动自己去找一条完美拟合训练数据的边界 |

> ⚠️ 注意高阶边界那一档：它在训练集上把正负例分得干干净净，**看起来效果极好，但这恰恰是高方差的典型表现**。评估一个模型好不好，绝不能只看它在训练集上的表现。

两个例子合起来是同一对结论：**模型太简单会欠拟合并带着高偏差，模型太复杂会过拟合并带着高方差，真正想要的是中间那种模型。**

## 二、对付过拟合的三条路

### 2.1 第一条路：补充更多训练数据

最直接的一条路是**收集更多训练数据**，也就是补充更多关于房屋面积与价格的样本。
训练集变大以后，学习算法会学到一个不那么扭曲的函数。因此即使继续使用高次多项式、或继续使用特征数量较多的那类函数，也可以成立。

> ⚠️ 这条路的限制在数据本身：**能拿到的样本常常只有这么多**，补充更多训练数据并不总是一个可选项。

### 2.2 第二条路：特征选择

前面那个模型把 $`x`$、$`x^2`$、$`x^3`$、$`x^4`$ 等一串多项式项都当作特征，数量很多。减少过拟合的一种办法，就是不把这些特征全部用上。
换一个例子：房价问题里除面积之外还可以放入一批其他特征（例如附近的咖啡店数量）。特征很多、训练样本又不足，同样会出现过拟合。

- **做法** —— 不再把全部特征都用上，而是挑出你认为对预测最有用的那一部分，只用这个子集。
- **代价** —— 被排除掉的特征里可能含有有用的信息，把一些信息直接取消掉，并不总是你想要的。
- **后续** —— 课程二里会看到一些算法，用来自动挑选最适合用于预测的那组特征。

### 2.3 第三条路：正则化

第三条路叫**正则化**。观察那个过拟合模型：它使用 $`x^2`$、$`x^3`$ 这类多项式特征，而**这类模型的参数往往相当大**。面对这些过大的参数，有两条不同的处理路径：
下表回答的是：同样是压制参数，两条路径的区别在哪。

| **路径** | **做法** | **特征是否保留** |
| --- | --- | --- |
| 把参数设为 0 | 删掉特征 $`x^4`$，等价于把它对应的参数设为 0 | 不保留（这就是特征选择） |
| 把参数压小但不归零 | 保留全部特征，只是不让特征产生过大的影响 | 全部保留 |

> 💡 **正则化的核心取舍**：影响过大正是有时会造成过拟合的原因，所以只要把影响压小即可，不必把特征删掉。按惯例，被缩小的参数是 $`w_1`$ 到 $`w_n`$ 这一组。

### 2.4 三条路的分工对照

下表回答的是：三种办法各自的前提与代价，以及该在什么时候选它。

| **办法** | **做法** | **前提与代价** |
| --- | --- | --- |
| 补充训练数据 | 加入更多样本，让高次多项式也能得到不那么扭曲的拟合 | 只有在确实拿得到更多数据时才用得上 |
| 特征选择 | 从全部特征里挑出你认为最有用的那一部分 | 被排除的特征里可能含有有用信息；自动挑选特征子集的算法在课程二里讲 |
| 正则化 | 保留全部特征，把 $`w_1`$ 到 $`w_n`$ 压小 | 不必删掉任何特征；课程里会反复用到，神经网络中同样如此 |

> 💡 三种办法里，**正则化是唯一不损失信息、又不依赖外部条件的那一条**，这也是它成为默认手段的原因。

## 三、把正则化写进代价函数

### 3.1 从一个设想说起：把高阶项的参数压下去

上一节的结论是：正则化通过让 $`w_1`$ 到 $`w_n`$ 的取值变小来减少过拟合。本节把这个直觉变成一个**修改后的成本函数**，让它真正可以用来应用正则化。
例子还是同一组数据：拟合二次函数得到的曲线相当不错；换成阶数很高的多项式，得到的曲线会过拟合数据。
换一个角度设想：有一种办法能把参数 $`w_3`$ 和 $`w_4`$ 变得**非常非常小、接近 0**，情况会怎样？
下表回答的是：加不加惩罚项，最小化的目标函数与结果有什么不同。

| **目标函数** | **结果** |
| --- | --- |
| 只最小化原来的平方误差 | $`w_3`$、$`w_4`$ 可以取较大值，得到一条过拟合数据的高阶曲线 |
| 再加上 $`1000 w_3^2`$ 和 $`1000 w_4^2`$ | 只要 $`w_3`$ 或 $`w_4`$ 稍大，总代价就被抬得很高，两个参数只能接近 0 |

这里的 $`1000`$ 只是**随手挑的一个大数目**，换成别的很大的数也可以。
最小化这个新目标，会把 $`w_3`$ 和 $`w_4`$ 推向 0 附近，$`x^3`$ 与 $`x^4`$ 两项的作用随之变得无足轻重，**模型实际上接近一个二次函数**，对数据的拟合比所有参数都能取大值时合理得多。

> ⚠️ 这个设想有一个隐藏前提：**已经知道数据背后的规律接近二次**。换成有 100 个特征的问题，事先无法判断 $`w_1`$ 到 $`w_{100}`$ 里哪些重要、哪些可以压小，挑着惩罚的做法就用不上了。所以下一步必须推广。

### 3.2 推广：不知道哪些重要，就全都惩罚一点

更一般地看正则化背后的思路：**参数的取值越小，就有点像模型越简单**（也许相当于特征更少），因此更不容易过拟合。
既然挑不出该惩罚哪些参数，就**一次惩罚所有参数、把它们整体压小一点**：在成本函数里加上 $`\lambda`$ 乘以 $`w_1`$ 到 $`w_n`$ 的平方和，其中 $`n`$ 是特征数量。
这里的 $`\lambda`$ 是希腊字母 lambda，称为**正则化参数（regularization parameter）**；它和学习率类似，也是需要自己选定的一个数值。

```math
\frac{\lambda}{2m}\sum_{j=1}^{n} w_j^2
```

> 💡 **为什么要除以 2m**：这一项和原来的平方误差项一样除以 $`2m`$，两项按同样的方式缩放，选出一个好的 $`\lambda`$ 会稍微容易一些；尤其是当训练集规模 $`m`$ 变大、找到更多训练样本时，之前选定的那个 $`\lambda`$ 也更有可能继续适用。

### 3.3 完整的正则化成本函数

把两项合起来，就得到带正则化的成本函数：

```math
J(\mathbf{w}, b) = \frac{1}{2m}\sum_{i=1}^{m}\left(f_{\mathbf{w},b}(\mathbf{x}^{(i)}) - y^{(i)}\right)^2 + \frac{\lambda}{2m}\sum_{j=1}^{n} w_j^2
```

这个新的成本函数**同时包含两件事**：
下表回答的是：两项各自负责什么目标。

| **项** | **目标** |
| --- | --- |
| 第一项（平方误差） | 把训练数据拟合好 —— 最小化预测值与实际值的平方差 |
| 第二项（正则化项） | 让参数 $`w_j`$ 保持较小 —— 倾向于减少过拟合 |

所选 $`\lambda`$ 的取值说明了这两个目标的**相对重要性**，也就是在两者之间如何权衡。

> ⚠️ **约定**：参数 $`b`$ 不放进惩罚项，这是按惯例来的。有些机器学习工程师和实际的学习算法实现也会加上 $`\frac{\lambda}{2m}b^2`$ 这一项，但两种做法在实践中的差别很小；本课程采用更常见的、不惩罚 $`b`$ 的约定。

### 3.4 正则化参数 λ 说明了什么

$`\lambda`$ 是这一套里唯一需要人为选定的新参数。它控制着「拟合数据」与「压制参数」之间的天平：

- $`\lambda`$ 越大 —— 参数被压得越狠，模型越简单，越倾向欠拟合。
- $`\lambda`$ 越小 —— 惩罚越弱，模型越自由，越倾向过拟合。

### 3.5 λ 取 0、极大、中间值

用线性回归的房价预测作为例子，$`f(\mathbf{x})`$ 就是线性回归模型，看 $`\lambda`$ 的不同取值会让学习算法做什么。
下表回答的是：$`\lambda`$ 的三个代表性取值各导向什么结果。

| **λ 的取值** | **对参数的约束** | **模型得到的结果** |
| --- | --- | --- |
| 0 | 正则化项被乘以 0，不起作用 | 拟合出一条过于复杂、摆动的高阶曲线，**过拟合** |
| 极大（例如 $`10^{10}`$） | 正则化项权重极重，只有让所有 $`w`$ 都接近 0 才能最小化代价 | $`w_1 \dots w_4`$ 都极接近 0，$`f(\mathbf{x})`$ 基本等于 $`b`$，拟合出一条水平直线，**欠拟合** |
| 不太小也不太大 | 参数被压小，但不为零 | 仍能像 4 阶多项式那样较好地拟合这批数据 |

> 💡 **两个极端放在一起看**：$`\lambda`$ 为 0 时模型过拟合，$`\lambda`$ 极大时模型欠拟合。要让模型拟合得合适，需要选一个**不太小也不太大**的 $`\lambda`$。这正是「同一把尺子量两端」——$`\lambda`$ 就是那个调节模型复杂度的旋钮。

## 四、正则化线性回归的梯度下降

### 4.1 只有 wj 的导数发生变化

正则化线性回归的代价函数由两段构成：前一段是通常的平方误差代价，后一段是新增的正则化项。要做的事仍然是找到让这个正则化代价最小的参数 $`\mathbf{w}`$ 和 $`b`$。
梯度下降的写法与之前一致：反复更新 $`w_j`$（$`j`$ 从 1 到 $`n`$）和 $`b`$，$`\alpha`$ 是学习率，一个很小的正数。加入正则化之后，更新式看上去和原来相同，**唯一的变化在代价函数**：$`J`$ 的定义变了。
差别落在导数上，而且只落在一处：
下表回答的是：加入正则化后，两个参数的导数各有什么变化。

| **导数** | **变化** |
| --- | --- |
| 对 $`w_j`$ 的导数 | 在原来的表达式后面**多出一项**，即 $`\frac{\lambda}{m}w_j`$ |
| 对 $`b`$ 的导数 | 与加入正则化之前**完全相同** |

> 💡 **原因**：只有 $`w_j`$ 变了，因为 $`b`$ 不做正则化，没有让 $`b`$ 缩小的意图；正则化项只促使 $`w_j`$ 被缩小，所以更新的变化只出现在 $`w_j`$ 上。

### 4.2 更新式的重排：每轮先乘一个略小于 1 的数

把 $`\frac{\lambda}{m}w_j`$ 这一项从末尾挪到前面并化简，$`w_j`$ 的更新式就变成：先算一个略小于 1 的系数乘上 $`w_j`$，再减去紧跟其后的那一项。
而被减去的这一项，正是**无正则化线性回归的常规梯度下降更新项**。
下表回答的是：加正则化前后，更新式差在哪里。

| **情况** | **更新式** |
| --- | --- |
| 无正则化 | $`w_j := w_j - \alpha\frac{1}{m}\sum\left(f(\mathbf{x}) - y\right)x_j`$ |
| 加入正则化后 | $`w_j := w_j\left(1 - \alpha\frac{\lambda}{m}\right) - \alpha\frac{1}{m}\sum\left(f(\mathbf{x}) - y\right)x_j`$ |

用一组示例数值来看 $`\left(1 - \alpha\frac{\lambda}{m}\right)`$ 有多接近 1：
下表回答的是：一组典型取值下，这个系数究竟是多少。

| **量** | **取值** |
| --- | --- |
| 学习率 $`\alpha`$ | 0.01 |
| 正则化参数 $`\lambda`$ | 1 |
| 训练集规模 $`m`$ | 50 |
| $`\alpha\frac{\lambda}{m}`$ | 0.0002 |
| $`1 - \alpha\frac{\lambda}{m}`$ | 0.9998 |

相乘的结果是一个很小的正数（约 0.0002），于是 $`1 - \alpha\frac{\lambda}{m}`$ 是一个**略小于 1 的数**，在这个例子里就是 0.9998。

> 💡 **正则化在每次迭代中做的事**：把 $`w_j`$ 乘上一个略小于 1 的数，再执行常规更新。效果是让 $`w_j`$ 在每轮迭代中**缩小一点点**。这也提供了正则化为什么能缩小参数的一个直观视角。

### 4.3 导数是怎么来的（可选）

这段推导完全是可选的，做实验和测验都用不到它，但它能说明前面的梯度表达式是怎么来的。
线性回归中 $`f(\mathbf{x}) = \mathbf{w}\cdot\mathbf{x} + b`$。按微积分规则求导，对 $`w_j`$ 的导数分成两部分：**平方误差项的部分**，以及**正则化项的部分**（后者不再包含 $`j`$ 从 1 到 $`n`$ 的求和）。

```math
\frac{\partial J}{\partial w_j} = \frac{1}{2m}\sum\left(\mathbf{w}\cdot\mathbf{x} + b - y\right)\cdot 2x_j + \frac{\lambda}{2m}\cdot 2w_j
```

两处 $`2`$ 分别与分母上的 $`2`$ 抵消，再把 $`\mathbf{w}\cdot\mathbf{x} + b`$ 写成 $`f(\mathbf{x})`$：

```math
\frac{\partial J}{\partial w_j} = \frac{1}{m}\sum\left(f(\mathbf{x}) - y\right)x_j + \frac{\lambda}{m}w_j
```

这就是正则化线性回归里用来计算梯度的表达式。

> 💡 用这套方法实现正则化线性回归，可以在**特征很多、训练集相对小**的情况下减轻过拟合，让线性回归在许多问题上表现得更好。

## 五、正则化逻辑回归

### 5.1 高阶特征下的过拟合

逻辑回归用很高阶的多项式特征来拟合时会过拟合。这时 $`z`$ 是一个高阶多项式，把它送入逻辑函数（sigmoid）得到 $`f`$，画出来的**决策边界会过于复杂**，在训练集上过拟合。
这**不只发生在多项式特征上**：用很多特征训练逻辑回归时，无论这些特征是多项式特征还是其他特征，都可能出现同样的情况。
处理办法与线性回归一样，在成本函数里加入对 $`w`$ 的正则项：

```math
\frac{\lambda}{2m}\sum_{j=1}^{n} w_j^2
```

以 $`\mathbf{w}`$ 和 $`b`$ 为变量最小化这个成本函数，效果是惩罚 $`w_1`$ 直到 $`w_n`$，**阻止它们变得太大**。这样即使拟合的仍然是带很多参数的高阶多项式，得到的决策边界也会更像一条能合理分开正负样本的边界，并有望泛化到训练集之外的新样本。

### 5.2 成本函数与梯度下降

带正则项的成本函数还是用梯度下降来最小化：对 $`w_j`$ 和 $`b`$ 做同时更新，更新规则本身与之前相同。和正则化线性回归一样，**唯一改变的地方在导数项上**：只有对 $`w_j`$ 求导得到的那一项有变化。
下表回答的是：正则化逻辑回归的两个更新式，求和均覆盖训练样本。

| **参数** | **更新式** |
| --- | --- |
| $`w_j`$ | $`w_j := w_j - \alpha\left[\frac{1}{m}\sum\left(f - y\right)x_j + \frac{\lambda}{m}w_j\right]`$ |
| $`b`$ | $`b := b - \alpha\frac{1}{m}\sum\left(f - y\right)`$ |

$`w_j`$ 的导数项里多出来的是 $`\frac{\lambda}{m}w_j`$ 这一项，它来自成本函数中的正则项。**一个例外**：$`b`$ 的更新完全不变，因为正则化只作用在 $`w_1`$ 到 $`w_n`$ 上，$`b`$ 不参与正则化。

### 5.3 与正则化线性回归的一致性

整体上，正则化逻辑回归的更新形式和正则化线性回归**几乎一模一样**，差别只在 $`f`$ 的含义：
下表回答的是：两套正则化更新式的唯一区别。

| **项目** | **正则化线性回归** | **正则化逻辑回归** |
| --- | --- | --- |
| $`f`$ 的含义 | $`\mathbf{w}\cdot\mathbf{x} + b`$ | 把 $`z`$ 送入 sigmoid 之后得到的输出 |
| 正则项 | $`\frac{\lambda}{2m}\sum w_j^2`$ | $`\frac{\lambda}{2m}\sum w_j^2`$ |
| 更新式形式 | 相同 | 相同 |

> 💡 这个「形式相同、只是 $`f`$ 不同」的结构，和上一页 `04_逻辑回归` 里「更新式相同 ≠ 同一个算法」是同一件事。判断两个算法是不是同一个，看的是预测函数而不是更新式的长相。

## 六、速查表

### 6.1 核心概念对照

下表回答的是：这一主题的全部关键术语一次对齐。

| **概念** | **含义** |
| --- | --- |
| 过拟合 / 高方差 | 模型太复杂，训练集上表现极好但泛化差，对数据极敏感 |
| 欠拟合 / 高偏差 | 模型太简单，连训练集都拟合不好 |
| 刚刚好 | 既不过拟合也不欠拟合，泛化最好 |
| 正则化 | 保留全部特征，通过惩罚让参数变小，从而降低模型复杂度 |
| $`\lambda`$ | 正则化参数，控制「拟合数据」与「压制参数」的权衡 |

### 6.2 正则化公式汇总

下表回答的是：正则化相关公式集中在哪、各用什么形式。

| **名称** | **公式** |
| --- | --- |
| 正则化项 | $`\dfrac{\lambda}{2m}\sum_{j=1}^{n} w_j^2`$ |
| 正则化线性回归成本 | $`\dfrac{1}{2m}\sum\left(f(\mathbf{x}) - y\right)^2 + \dfrac{\lambda}{2m}\sum w_j^2`$ |
| 对 $`w_j`$ 的偏导 | $`\dfrac{1}{m}\sum\left(f(\mathbf{x}) - y\right)x_j + \dfrac{\lambda}{m}w_j`$ |
| 对 $`b`$ 的偏导 | $`\dfrac{1}{m}\sum\left(f(\mathbf{x}) - y\right)`$ |
| $`w_j`$ 的更新式 | $`w_j\left(1 - \alpha\dfrac{\lambda}{m}\right) - \alpha\dfrac{1}{m}\sum\left(f(\mathbf{x}) - y\right)x_j`$ |

### 6.3 易错点对照

下表回答的是：这一主题最容易搞混的地方对应怎么理解。

| **易错点** | **正确理解** |
| --- | --- |
| 训练集误差为 0 说明模型好 | 恰恰是高方差的信号，要看泛化能力 |
| 以为过拟合就是「拟合得不够好」 | 是拟合得**太好**，好过了头 |
| 以为正则化会删掉特征 | 正则化**保留全部特征**，只把参数压小；删特征属于特征选择 |
| $`\lambda`$ 越大越好 | $`\lambda`$ 极大反而欠拟合，必须取中间值 |
| 给 $`b`$ 也加了惩罚 | 按惯例**不惩罚 b**，只惩罚 $`w_1`$ 到 $`w_n`$ |
| 以为正则化项不用除以 $`2m`$ | 与平方误差项一样除以 $`2m`$，便于选定 $`\lambda`$ |
| 以为加了正则化后更新式要重写 | 只需在 $`w_j`$ 上多乘 $`\left(1 - \alpha\frac{\lambda}{m}\right)`$，$`b`$ 完全不变 |

---

## 小结

> ✅ **一句话结论**：过拟合与欠拟合是模型复杂度的两端——前者高方差、后者高偏差，特征太多走向过拟合、太少走向欠拟合；对付过拟合有三条路（补数据、选特征、正则化），其中**正则化是唯一不损失信息又不依赖外部条件的**；做法是在成本函数里加 $`\frac{\lambda}{2m}\sum w_j^2`$，只惩罚 $`w_1`$ 到 $`w_n`$ 而不惩罚 $`b`$；它的梯度下降只是在 $`w_j`$ 上多乘一个略小于 1 的系数 $`\left(1 - \alpha\frac{\lambda}{m}\right)`$，$`b`$ 的更新完全不变，线性回归与逻辑回归两套更新式形式相同、差别只在 $`f`$ 的含义；$`\lambda`$ 是那个调节旋钮——**取 0 就过拟合，取极大就欠拟合，必须取中间值**。
