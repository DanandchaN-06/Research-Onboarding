## 一、神经网络是什么

### 1.1 课程二的两条主线

课程二讲两类算法：**神经网络（也常叫深度学习）**与**决策树**，都要求亲手实现；另有一条贯穿全程的内容是**构建机器学习系统的实用建议**。推进顺序是先做**推理**（用别人训练好的参数做预测），再学**训练**。

### 1.2 从几次起落说起

神经网络的动机是造出能模仿大脑的软件。这条路走了七十多年，经历了几次起落：
下表回答的是：神经网络发展过程中的几个关键节点。

| **时间** | **事件** |
| --- | --- |
| 1950 年前后 | 研究开始 |
| 1980 年代到 1990 年代初 | 再次受关注，在手写数字识别上带来一阵兴奋 |
| 1990 年代后期 | 热度退去 |
| 约 2005 年起 | 真正复兴，渐渐被称为「深度学习」 |
| 2012 年 | ImageNet 时刻，在计算机视觉上产生很大影响，之后进入文本与自然语言处理 |

> 💡 深度学习和神经网络原本指几乎同一件事。「深度学习」听起来更好——又「深」又在「学习」，于是成了这门技术的品牌名。**今天用到的网络，与大脑实际如何学习已经几乎没有关系。**

### 1.3 人工神经元

生物神经元里，输入线叫**树突**，输出线叫**轴突**。这些术语**不必记**，搭网络用不到它们。
真正要用的模型简单得多：**一个神经元接收一个或多个数字，做某种计算，输出另一个数字**；这个输出接着成为下游神经元的输入。
实际搭建时不会一次只造一个，而是同时模拟许多个——几个神经元一起接收几个数字，输出另外几个数字。

### 1.4 生物类比能带到多远

这个类比是**松散**的。人脑究竟如何工作，今天仍然不清楚；想从大脑反向工程出真正的智能，靠目前这点了解走不了太远。但接下来这套极度简化的模型，仍然足以搭出强大的深度学习算法。

> 💡 神经网络的起点确实受生物学启发，但**越往深处学，越不必把生物学动机看得太重**。

### 1.5 为什么是现在：数据与算力

神经网络为什么只在最近这些年才起飞？答案落在两件事上。
下表回答的是：数据量与算力各自起了什么作用。

| **推动力** | **具体表现** |
| --- | --- |
| 数据量增长 | 互联网兴起、手机普及、社会数字化，大量原本留在纸上的记录变成数字记录 |
| 算力 | GPU 原本为图形处理设计，结果在深度学习上同样非常强大 |

更关键的是**不同规模算法对数据的反应不同**：

- 传统学习算法拿到更多数据后表现很难再提升，曲线趋于持平。
- 小的神经网络稍好一些，但也大致同样趋于持平。
- **非常大的神经网络在某些应用上表现会持续上升。**

于是有了这样一类场景：手里确实有大量数据时，训练一个很大的神经网络来利用它，就能做到此前传统算法做不到的事。

> 💡 **一句话记住**：神经网络的起步出于模仿大脑的兴趣，起飞则靠数据量增长与 GPU 算力；**网络足够大，才能把这些数据用起来**。

## 二、从单个神经元到多层网络

### 2.1 单个神经元就是一次逻辑回归

最小的计算单元就是逻辑回归，输出写成：

```math
a = \frac{1}{1 + e^{-(wx + b)}}
```

$`x`$ 是输入特征，$`w`$ 和 $`b`$ 是这个单元的参数，$`a`$ 是算出来的结果。在需求预测里，$`a`$ 可以理解成「是爆款」这个判断成立的概率。

### 2.2 激活值：为什么改叫 a

同样的输出在逻辑回归里记作 $`f(x)`$，进入神经网络后改用字母 $`a`$ 表示，取自 **activation**，中文叫**激活值**。

> 💡 激活值的含义是「**一个神经元向它下游的神经元输出高值的程度**」。改名字是为了和逐层的记号体系配套，数学含义没有变。

### 2.3 一个例子：T 恤爆款预测

判断一件 T 恤会不会成为爆款，能观察到的信息是四个特征：**价格、运费、营销投入、材质**。中间隔着三个更容易把握的因素，每个交给一个人工神经元估计。
下表回答的是：三个中间判断各自主要依赖哪些原始特征。

| **中间判断** | **主要依赖的特征** |
| --- | --- |
| 可负担性 | 价格、运费 |
| 知名度 | 营销投入 |
| 感知质量 | 价格、材质 |

注意**价格在两个判断里都起作用**：定价很高的 T 恤，人们有时会因为贵而认为它质量更好。

### 2.4 一层是什么

左边三个神经元读同样的输入、又一起输出几个数，因此被合成**一层**；右边给出最终判断的那个神经元自己也是一层。

> 💡 **层的定义**：一组接收相同或相似输入、并一起输出若干数值的神经元。**一层可以有多个神经元，也可以只有一个。**

整个网络的计算顺序：先输入四个数，中间层用这四个数算出三个新数（也叫激活值），输出层再用这三个数算出一个数作为最终预测。输入端那几个数组成的列表就叫**输入层**。

### 2.5 隐藏层为什么叫隐藏层

如果逐个手工指定接线——可负担性只看价格和运费、知名度只看营销投入——网络一大，这份工作会很重。这里可以做一处简化：**中间层的神经元直接接收前一层输出的全部数值**。
那为什么叫「隐藏层」？名字来自**训练数据里能看到什么**：训练集同时给出 $`x`$ 和 $`y`$，四个特征是已知的，最终有没有成为爆款也是已知的；但可负担性、知名度、感知质量这三个**中间值不会出现在数据里**。这些量对观察者是隐藏的，中间那一层因此得名。

### 2.6 特征不必手工设计

房价预测那一课里，地块面积由**人工构造**：把临街宽度和进深相乘得到 $`x_1 \times x_2`$，再交给模型，这属于手工特征工程。神经网络把这一步**交给网络自己**——中间层的神经元自己组合出需要的中间量，不需要人决定它该读哪些数值。

> 💡 人只要提供原始特征，**隐藏层该组合出哪些中间量、每个神经元该看什么，由网络自己学出来**。

### 2.7 逐层组合：人脸识别的例子

一张 1000×1000 的照片是一个像素亮度矩阵，排成向量后是一百万个数字，这就是网络的输入。网络逐层提取的特征从局部走向整体：
下表回答的是：人脸识别中各层分别在处理什么范围的信息。

| **层** | **处理的对象** |
| --- | --- |
| 第一层 | 画面很小范围内的线条与边缘方向 |
| 第二层 | 把小块拼成眼睛、鼻子这类面部局部 |
| 第三层 | 范围更大的整体轮廓，对应整张脸的形状 |
| 输出层 | 据此判断照片中的人是谁 |

这些中间特征**没有被人事先指定**，由网络在训练数据上自己学出来。换一套数据，学出来的特征跟着变：同样的算法用在汽车图片上，第一层仍偏小范围的边缘线条、第二层开始检测汽车局部、第三层给出车身形状——**层级结构保持一致，每一层负责什么由训练数据决定**。

### 2.8 更深的网络与多层感知机

隐藏层可以不止一层。例如输入先送进第一层隐藏层得到三个激活值，这三个值再送进第二层算出两个值，最后由输出层给出预测；也可以更深。
搭网络时需要自己定两件事：**用几个隐藏层、每层放几个神经元**。

> 💡 在别的文章里看到的 **multilayer perceptron（多层感知机）**，指的就是这类网络。

## 三、一层的计算与记号

### 3.1 每个单元做一次逻辑回归

把隐藏层放大，它输入 4 个数字，而这 4 个数字同时是 3 个神经元各自的输入，每个神经元实现的是一个小型逻辑回归单元：

```math
a_1 = g(\mathbf{w}_1 \cdot \mathbf{x} + b_1), \qquad g(z) = \frac{1}{1 + e^{-z}}
```

括号里的 $`\mathbf{w}_1 \cdot \mathbf{x} + b_1`$ 就是逻辑回归中熟悉的 $`z`$ 值。第二个单元拥有自己的参数 $`\mathbf{w}_2`$、$`b_2`$，输出 $`a_2 = g(\mathbf{w}_2 \cdot \mathbf{x} + b_2)`$；三个单元各自输出一个激活值，合起来构成隐藏层的结果。

### 3.2 层的编号

网络有了多层就需要给层编号，按惯例：

- **隐藏层是第 1 层**，**输出层是第 2 层**，输入层有时也叫**第 0 层**。
- 今天的网络可以有几十层甚至上百层。

> ⚠️ **数网络的层数时不把输入层算进去**。所以「第 0 层输入、第 1 到 3 层隐藏、第 4 层输出」的网络，被称为一个 **4 层网络**。

### 3.3 方括号上标与下标

用**方括号里的上标表示层号**，**下标表示这一层里的第几个单元**：
下表回答的是：同一套记号里，方括号和下标各指什么。

| **记号** | **含义** |
| --- | --- |
| $`a^{[1]}`$ | 第 1 层（隐藏层）的输出向量 |
| $`w_1^{[1]}`$、$`b_1^{[1]}`$ | 第 1 层第 1 个单元的参数 |
| $`w_2^{[1]}`$、$`b_2^{[1]}`$ | 第 1 层第 2 个单元的参数 |

点乘两边的上标各有来源：$`w_1^{[3]} \cdot a^{[2]}`$ 里的 3 表示这是第 3 层的参数，**2 表示点乘的对象是第 2 层的输出，而第 2 层的输出正是第 3 层的输入**。

### 3.4 通用算式

把具体某一层的算式推广到任意一层 $`L`$、这一层的任意一个单元 $`j`$：

```math
a_j^{[L]} = g\left(\mathbf{w}_j^{[L]} \cdot \mathbf{a}^{[L-1]} + b_j^{[L]}\right)
```

- $`\mathbf{w}_j^{[L]}`$ 是第 $`L`$ 层第 $`j`$ 个单元的权重向量
- $`\mathbf{a}^{[L-1]}`$ 是**上一层**输出的激活值，所以写 $`L-1`$
- $`b_j^{[L]}`$ 是对应的偏置

为了让记号前后一致，输入特征向量 $`\mathbf{x}`$ 另取一个名字：$`\mathbf{a}^{[0]}`$。这样 $`L`$ 取 1 时同一个算式仍然成立，其中的 $`\mathbf{a}^{[0]}`$ 就是输入 $`\mathbf{x}`$。

> 💡 **整套记号只需记两条**：方括号里的数字指向层号，下标指向这一层里的第几个单元；**点乘用的向量永远来自上一层**，所以写 $`L-1`$，不写 $`L`$。

> 💡 式子里的 $`g`$ 在神经网络语境里叫**激活函数**，因为它输出的就是这个激活值。目前见到的只有 sigmoid，后面会看还有哪些函数可以放进 $`g`$ 的位置。

### 3.5 从概率到 0/1

输出层只剩下一个神经元，做的仍是一次逻辑回归运算。它的输出是一个概率，要得到 0 或 1 的判断，就在 **0.5 处设阈值**：大于 0.5 预测 $`\hat{y} = 1`$，小于 0.5 预测 $`\hat{y} = 0`$。如果只想要概率，保留原值不做阈值化即可。

## 四、前向传播

### 4.1 什么是前向传播

把前面各部分组合起来，就得到让神经网络做推理、给出预测的算法，这个算法叫**前向传播（forward propagation）**。
计算按固定顺序进行：第一隐藏层把输入算成 $`a^{[1]}`$，第二隐藏层把 $`a^{[1]}`$ 算成 $`a^{[2]}`$，输出层再把 $`a^{[2]}`$ 算成 $`a^{[3]}`$。整条计算链可以整体写成 $`f(x)`$。

### 4.2 示例：25–15–1 网络

用一个简化的手写数字例子展开：输入一张 **8×8** 的图片，判断它是 0 还是 1（二分类）。64 个像素强度的范围是 0 到 255，255 表示明亮的白色，0 表示黑色。
下表回答的是：这个网络各层的规模与输出形状。

| **层** | **单元数** | **输出** |
| --- | --- | --- |
| 第一隐藏层 | 25 | $`a^{[1]}`$ 有 25 个数，参数 $`W_1`$ 到 $`W_{25}`$、$`b_1`$ 到 $`b_{25}`$ |
| 第二隐藏层 | 15 | $`a^{[2]}`$ 有 15 个数 |
| 输出层 | 1 | $`a^{[3]}`$ 是一个标量 |

如果需要的是类别标签，可以可选地把 $`a^{[3]}`$ 在 0.5 处取阈值。

### 4.3 代码写法：TensorFlow

以一个烘焙咖啡的例子说明：输入是**温度**与**时间**两个特征，$`y`$ 取 1 表示好咖啡、0 表示不好的咖啡。只有温度与时长都落在合适区间的那段窄带里才是好咖啡。

```python
x = np.array([[200.0, 17.0]])
layer_1 = Dense(units=3, activation="sigmoid")
a1 = layer_1(x)
layer_2 = Dense(units=1, activation="sigmoid")
a2 = layer_2(a1)          # a2 = 0.8
if a2 >= 0.5:
    yhat = 1               # 好咖啡
```

`Dense` 是层的类型之一，`units` 是这一层的单元数，`activation` 指定激活函数。**layer1 本身就是一个函数**，把它作用在 $`x`$ 上得到 $`a_1`$。
按惯例可以把各层直接写进 `Sequential`，不必先赋给变量：

```python
model = Sequential([
    Dense(units=3, activation="sigmoid"),
    Dense(units=1, activation="sigmoid"),
])
model.compile(...)
model.fit(X, Y)              # 训练：调各层权重
model.predict(x_new)         # 推理：一次完成前向传播
```

> 💡 换到手写数字识别，写法照旧，**变的只是输入规模**：$`x`$ 从两个数变成一个像素强度向量，第一层写成 `Dense(units=25, activation="sigmoid")`，后面再接第二、第三层。两个例子的骨架一致——**先定义层，把上一层结果交给下一层，最后对输出做判断**。

### 4.4 从零实现：dense 函数

上一节的写法是为每个神经元单独写一行代码，神经元一多代码就变长。把它换成通用写法：把同一层的计算收进一个函数。**权重矩阵的每一列对应一个神经元**，偏置按同样顺序堆成一维数组。

```python
def dense(a_in, W, b, g):
    units = W.shape[1]        # W 的列数 = 这一层的神经元个数
    a_out = np.zeros(units)
    for j in range(units):
        w = W[:, j]           # 取出 W 的第 j 列
        z = np.dot(w, a_in) + b[j]
        a_out[j] = g(z)
    return a_out
```

有了它，把几层接起来就只剩几行：

```python
a1 = dense(x,  W1, b1)
a2 = dense(a1, W2, b2)
a3 = dense(a2, W3, b3)
a4 = dense(a3, W4, b4)
```

> 💡 代码里用的是**大写 W**。线性代数惯例用大写字母表示矩阵、小写表示向量和标量，所以权重矩阵写作 $`W`$ 而不是 $`w`$。

### 4.5 为什么要自己实现一遍

框架里调用一次前向传播只有一行代码，但问题在于：**照着敲下五行代码，就说你搭出了一个复杂的神经网络，这五行到底做了什么？**

> ⚠️ 实际工作中多数工程师很少自己实现前向传播，**理解算法的用处体现在出问题的时候**：能自己想清楚哪里需要修改、哪种做法可能有效。跑机器学习算法时很多时候就是跑不通，**调试能力是有效工程师必须具备的**。

## 五、向量化实现

### 5.1 数据表示：矩阵与张量

**维度约定**：矩阵的维度写成「行数 × 列数」，行数永远在前。2 行 3 列读作 2×3。

```python
x = np.array([[1, 2, 3],
              [4, 5, 6]])       # 2×3
```

下表回答的是：同样两个数字，三种写法各是什么。

| **写法** | **结构** | **名称** |
| --- | --- | --- |
| `[[200, 17]]` | 1 行 2 列，二维数组 | 行向量 |
| `[[200], [17]]` | 2 行 1 列，二维数组 | 列向量 |
| `[200, 17]` | 没有行也没有列 | Python 一维数组 |

> ⚠️ 只留**一层方括号**时得到的是 Python 一维向量，**它既没有行也没有列**。课程一的线性回归和逻辑回归用的就是这种一维数组；而 **TensorFlow 处理数据时用矩阵表示**，看到的张量输出都带二维形状。

在 TensorFlow 里打印 $`a_1`$ 会显示为 `tf.Tensor`，并标注 `shape=(1, 3)`，`dtype=float32`。**float32 表示浮点数，每个数字在内存中占 32 位**，名字就来自这 32 位。第二层只有一个单元，$`a_2`$ 取值虽然是一个数，在 TensorFlow 里**依然按二维数组处理，是 1×1 矩阵**。
两套表示并存是因为历史：NumPy 先出现，Google Brain 随后构建了 TensorFlow，各自形成了一套约定。要对张量取 NumPy 形式的数据，调用 `.numpy()` 即可。

### 5.2 为什么要向量化

过去十年深度学习能不断扩大网络规模，一个原因在于**神经网络可以做向量化，能够借助矩阵乘法高效实现**。并行计算硬件很擅长处理超大矩阵乘法——GPU 属于这一类。**没有这些做法，深度学习很难达到今天的规模。**

### 5.3 一层前向传播的向量化写法

同一段前向传播，改写后只需要几步：

```python
Z = np.matmul(X, W) + B
A_out = g(Z)
return A_out
```

$`X`$ 写成双层方括号变成二维数组，$`W`$ 不变，偏置改用大写 $`B`$（一个 1×3 的二维数组）。$`g`$ 逐元素作用到矩阵 $`Z`$ 上。**在向量化实现里，所有量都是二维的。**

### 5.4 矩阵乘法的规则

**点积**是矩阵乘法的基本单元：把对应位置的元素两两相乘再相加。例如 (1, 2) 与 (3, 4) 的点积是 $`1 \times 3 + 2 \times 4 = 11`$。
**转置**把列向量平放成行向量：$`a`$ 原本是 2×1 的列向量，取转置后变成 $`a^T`$，即 1×2 的行向量。于是同一个点积有两种写法：$`z = a \cdot w`$ 与 $`z = a^T w`$。
**行向量乘矩阵**：让 $`a^T`$ 依次与 $`W`$ 的每一列做点积，每个点积的结果成为 $`z`$ 的一个元素。
**矩阵乘矩阵**：把矩阵想成一组并排的列向量，对 $`A^T`$ 的**每一行**重复同一套点积。

> 💡 **看到矩阵，就把它想成一组列；看到矩阵的转置，就把它想成一组行。** 这种看法在处理神经网络的具体实现时同样有用。

乘法能成立只要求一件事：**第一个矩阵的列数等于第二个矩阵的行数**。这条限制来自内积本身——内积只在两个长度相同的向量之间进行。
下表回答的是：矩阵乘法的一般规则。

| **项目** | **规则** |
| --- | --- |
| 维度条件 | 中间两个数必须相等，它们同时是参与内积的向量长度 |
| 结果形状 | 行数取自第一个矩阵，列数取自第二个矩阵 |
| 一般形式 | $`(m \times n)`$ 乘 $`(n \times p)`$ 得到 $`(m \times p)`$ |

### 5.5 NumPy 中的写法

```python
A_T = A.T                    # 转置：把 A 的列重新排成行
Z = np.matmul(A.T, W)        # 矩阵乘法
Z = np.matmul(A.T, W) + b    # 再加偏置
a_out = g(Z)                 # 逐元素激活
```

`A.T` 直接给出转置。读别人代码时还可能遇到 `A.T @ W`，**@ 同样是在调用 matmul**，做的是同一件事；用 `np.matmul` 写出来更清楚。

## 六、额外的层类型：卷积层

### 6.1 稠密层与局部连接

前面几讲用的都是**稠密层**。这一节介绍另一种层类型：**卷积层**。
下表回答的是：两种层在连接方式上的根本区别。

| **层类型** | **每个神经元读什么** |
| --- | --- |
| 稠密层 | 上一层传来的**全部**激活值 |
| 卷积层 | 输入中的**一个局部区域**，激活值由这一小块里的输入决定 |

以一张手写数字 9 的图像为例，给不同隐藏单元分配图像上不同的小块矩形区域，每个单元只连接自己那块区域里的像素。

### 6.2 局部连接的两个好处

下表回答的是：为什么不让每个神经元都看全部像素。

| **好处** | **原因** |
| --- | --- |
| 计算更快 | 每个神经元只处理输入中的一小块，参与运算的数据更少 |
| 训练数据更少、更不易过拟合 | 使用卷积层的网络只需要较少的训练数据 |

### 6.3 一维例子：EKG 信号

把输入从二维图像换成一维，例子是 EKG（心电图）信号的分类：在胸口放两个电极，记录电压随心跳的起伏，得到一串数字（例如 100 个时间点上的 100 个值）。把它竖放就得到输入 $`x_1`$ 到 $`x_{100}`$，**每个隐藏单元各连接其中一段窗口，而不读取全部 100 个数**。

### 6.4 设计选择与其他层类型

EKG 这个例子已经体现出两项设计选择：

- **窗口的长度**：每个隐藏单元连接多少个输入。例子里是连续 20 个时间点。
- **窗口错开的幅度**：相邻隐藏单元之间移过多少个输入。例子里是 10 个，相邻两段窗口因此有一半重叠。

> 💡 由卷积层构成的网络有时被称为**卷积神经网络**。层类型也不只有卷积一种——**Transformer、LSTM** 这类名字背后是不同的层设计，不少较新的研究方向都在尝试新的层类型以及组合方式。

## 七、速查表

### 7.1 记号速查

下表回答的是：本文出现的所有记号一次对齐。

| **记号** | **含义** |
| --- | --- |
| $`a`$ | 激活值，一个神经元向下游输出高值的程度 |
| $`a^{[L]}`$ | 第 $`L`$ 层的输出向量 |
| $`a_j^{[L]}`$ | 第 $`L`$ 层第 $`j`$ 个单元的激活值 |
| $`w_j^{[L]}`$、$`b_j^{[L]}`$ | 第 $`L`$ 层第 $`j`$ 个单元的权重与偏置 |
| $`\mathbf{a}^{[0]}`$ | 输入特征向量 $`\mathbf{x}`$ 的别名 |
| $`W`$ | 权重矩阵，大写表示矩阵，**每一列对应一个神经元** |

### 7.2 关键公式

下表回答的是：从单个单元到整层向量化的全部核心公式。

| **名称** | **公式** |
| --- | --- |
| 单个神经元 | $`a = \dfrac{1}{1 + e^{-(\mathbf{w} \cdot \mathbf{x} + b)}}`$ |
| 第 $`L`$ 层第 $`j`$ 个单元 | $`a_j^{[L]} = g\left(\mathbf{w}_j^{[L]} \cdot \mathbf{a}^{[L-1]} + b_j^{[L]}\right)`$ |
| 前向传播（逐层） | $`a^{[1]} \to a^{[2]} \to a^{[3]}`$，整体记作 $`f(x)`$ |
| 一层的向量化 | $`Z = \mathrm{matmul}(A^T, W) + b`$，$`A_{out} = g(Z)`$ |
| 矩阵乘法维度 | $`(m \times n)`$ 乘 $`(n \times p)`$ 得到 $`(m \times p)`$ |

### 7.3 易错点对照

下表回答的是：这一部分最容易搞混的地方对应怎么理解。

| **易错点** | **正确理解** |
| --- | --- |
| 数层数时把输入层也算进去 | **不把输入层算进去**，第 0 层是输入层 |
| 点乘写成 $`a^{[L]}`$ | 输入的**上一层的输出**，所以写 $`a^{[L-1]}`$ |
| 把 $`[200, 17]`$ 当成矩阵 | 只有**一层方括号**，是一维数组，没有行也没有列 |
| 以为单输出层的输出是标量 | 在 TensorFlow 里仍是 **1×1 矩阵** |
| 矩阵乘法前不检查维度 | 必须**第一个的列数 = 第二个的行数**，否则无法做内积 |
| 以为 $`@`$ 和 `np.matmul` 不同 | 两者做的是**同一件事** |
| 以为有了框架就不必懂底层 | **调试能力**才是理解算法的用处所在 |

---

## 小结

> ✅ **一句话结论**：神经网络的最小单元就是一次逻辑回归，输出叫**激活值**；把读同样输入的神经元合成**一层**，中间层因「训练数据里看不到这些值」而得名**隐藏层**，其价值在于**特征由网络自己学、不必手工设计**；记号只有两条——**方括号是层号、下标是单元序号**，点乘的对象永远来自上一层所以写 $`L-1`$；把各层依次算下去就是**前向传播**，而一层的前向传播可以整体写成一次矩阵乘法 $`Z = \mathrm{matmul}(A^T, W) + b`$（要求中间两个维度相等），这正是神经网络能吃下大数据与 GPU 算力的原因；此外还有**卷积层**这类只做局部连接的层，它更快、更不容易过拟合。
