# 02_线性回归

## 一、线性回归模型

> 🧭
>
> 归属：监督学习 · 回归模型
> 分类：单变量线性回归、多变量线性回归
> 模型形式：$`f_{w,b}(x) = wx + b`$

### 1.1 模型与记号

线性回归是这门课程里第一个展开讲解的学习模型，也是实际中使用最广的一种。后面更复杂的模型会反复用到它建立起来的概念，所以先在这里把整个学习过程走一遍。
用来拟合训练集的模型是一个线性函数：

```math
f_{w,b}(x) = wx + b
```

其中 w 和 b 叫做模型的**参数**（parameters）。

> 📌 在机器学习中，参数指的是训练过程中可以调整、用来改进模型的变量；这两个参数有时也被称为**系数**（coefficients）或**权重**（weights）。

**训练集：**用来训练模型的数据。整个流程分两步：

1. **训练** — 让模型从训练集的 x 与 y 配对中学习。
2. **预测** — 把 x 交给训练好的模型，得到它给出的 $`f(x)`$，即预测值 ŷ。

下表回答的是：课程里那套记号各自指什么（以房价预测为例）。

| **记号** | **含义** | **在房价例子中** |
| --- | --- | --- |
| **x** | 输入变量，也叫特征或输入特征 | 房子的面积；第一个训练样本的 x 等于 2104 平方英尺 |
| **y** | 输出变量，也叫目标变量，是想要预测的量 | 房子的价格；第一个训练样本的 y 等于 400，因为纵轴以千美元为单位，也就是 40 万美元 |
| **m** | 训练样本的数量 | 47 |
| **(x, y)** | 一个训练样本 | 第一个训练样本是 (2104, 400) |
| **x(i), y(i)** | 第 i 个训练样本，上标 i 对应表格里的第 i 行，可以取 1 到 47 | i = 1 时，x(1) = 2104，y(1) = 400 |

### 1.2 学习算法做了什么：函数 f 与预测 ŷ

监督学习的训练集里同时包含输入特征和输出目标：这里的输入特征是房子面积，输出目标是房价。输出目标就是模型要学习的正确答案。

1. **把训练集交给学习算法**

输入特征和输出目标一起喂给监督学习算法。

2. **算法产出一个函数 f**
3. **用 f 对新的输入给出预测**

f 接收一个新的输入 x，输出对 y 的估计或预测，记作 ŷ，写法是在 y 上面加一个小帽子。
这套流程里的三个角色各有名字：函数 f 叫模型，x 叫输入或输入特征，模型的输出就是预测 ŷ。

### 1.3 成本函数 J(w, b)：用平方误差衡量直线拟合得好不好

衡量拟合得好不好要用成本函数：把每个点的预测误差平方、求和、除以 m、再除以 2，得到 J(w,b)。

#### 1.3.1 成本函数的四项构造

1. **单个样本的平方误差**

取预测值与真实目标之差，再平方：

```math
(\hat{y}^{(i)} - y^{(i)})^2
```

因为 $`\hat{y}^{(i)} = f(x^{(i)})`$，括号里也可以写成 $`(f(x^{(i)}) - y^{(i)})`$。这个量衡量第 i 个点上模型偏了多远。

2. **对所有训练样本的平方误差求和**
3. **除以 m 取平均**
4. **再除以 2**

机器学习里的惯例是除以 2m。多出来的这个 2 只是为了让后面的计算更简洁；除或不除，成本函数都成立。

#### 1.3.2 平方误差成本函数

```math
J(w,b) = \frac{1}{2m}\sum_{i=1}^{m}(f_{w,b}(x^{(i)}) - y^{(i)})^2
```

> 📌 括号里的 $`f_{w,b}(x^{(i)})`$ 就是预测值 $`\hat{y}^{(i)}`$，两种写法等价。

#### 1.3.3 把 b 固定为 0 时 J 的形状

把 b 固定为 0 后 J 只随 w 变化：w 给出直线的斜率，b 是纵轴截距——w=0、b=1.5 是水平线，w=0.5、b=0 过原点，w=0.5、b=1 与纵轴交于 1。用三个点 (1,1)、(2,2)、(3,3) 试算：w=1 得 J=0，w=0.5 得 ≈0.58，w=0 得 ≈2.33，w=−0.5 得 5.25。最低点落在 w=1，此时直线正好穿过三个点。

## 二、成本函数的可视化

下面两节把「J 长什么样」走一遍。

### 2.1 J 长什么样：从曲线到曲面（p07–p08）

只有一个参数 w 时，J 是一条 U 形曲线。把 b 也放开后，J(w,b) 的图像变成**三维的碗状曲面**：两个水平轴是 w 和 b，高度是 J。曲面上每个点都对应一组具体参数，比如取 w=0.06、b=50 会得到一条持续低估房价的直线。三维图不好读，于是改用**等高线图**：用水平面横切曲面，切出的点 J 相同，投影到平面上就是一条闭合椭圆，层层相套，**J 的最小值落在同心椭圆的正中心**。

### 2.2 一组参数就是图上的一个点（p09）

训练数据固定时，换一组 w、b 就换一条直线，J 也取到新值：w=-0.15、b=800 的直线从高处向右下走，代价很高；w=0、b=360 是水平线，仍然偏高；另一组偏离数据更远，代价更高；还有一组走向与数据一致，代价接近最小。**一组 (w,b) 同时对应图上一个点、一条拟合直线和一个 J 值**。靠人眼在等高线里找最小值并不现实，模型变复杂后更行不通，所以需要一个能写成代码的算法。

## 三、梯度下降

---
**梯度下降**是一种最常用的优化算法，用来**最小化目标函数**（在机器学习中通常叫损失函数）。一句话概括：**让参数沿着损失函数下降最快的方向，一步步走到最低点。**
因为梯度指向函数值上升最快的方向。要最小化损失，就要往反方向走，所以是减去梯度。
它可以想象成站在起伏的地形上：原地环顾找最陡的下坡方向，朝那个方向迈一小步，到新位置再重新环顾，如此重复直到谷底。做法是从一个初始猜测出发（线性回归常取 w=0、b=0），**每次把 w 和 b 各改动一点，让 J 变小**；起点不同，最终可能落到不同的局部最小值。

### 3.1 更新式与它每个符号（p11）

这一讲把梯度下降从公式落到具体实现。每一步做两件事：更新 w，更新 b。

```math
w := w - \alpha \frac{\partial}{\partial w} J(w,b)
```

```math
b := b - \alpha \frac{\partial}{\partial b} J(w,b)
```

下表回答的是：更新式里每个符号各自是什么。

| **部分** | **含义** |
| --- | --- |
| `:=` | 赋值号，把右边算出的值存进左边的变量 |
| `α` | 学习率（learning rate），控制每一步走多远 |
| 导数项 | 代价函数对参数的导数，与 α 一起决定这一步怎么调整 |

读法：拿当前的 w，减去 α 乘以导数项，得到新的 w；b 的式子与它相同，只把导数项换成 J 对 b 的导数。
**等号在这里是赋值，不是断言。** 写成代码就是 `a = c`（把 c 的值存进 a）、`a = a + 1`（把 a 加一后存回 a）。数学里的等号有时表示两边相等这个断言，而作为断言 `A = A + 1` 不可能成立；Python 等语言把「判断相等」写成 `==`。课程里两种含义都会出现，写等号时会说明当前属于哪一种，**读更新式时一律按赋值来理解**。

> 💡 把代价函数想成一张曲面，整个过程就是一小步一小步往下走，直到走到谷底。

### 3.2 收敛：什么时候停下来

梯度下降就是重复上面两条更新步骤，直到算法收敛。**收敛**指到达局部最小值，此时 w 和 b 在每一步之后都不再明显改变。
式子怎么写是一回事，按什么顺序执行是另一回事。两条更新式里的 w 和 b 都要用**更新前**的值参与计算，再一起写回，做法是先把右边算成临时值。
下表回答的是：同时更新与非同时更新的写法差别在哪。

| **写法** | **做法** | **结果** |
| --- | --- | --- |
| **同时更新**（正确） | 先算 `temp_w = w - α·∂J/∂w`、`temp_b = b - α·∂J/∂b`，再 `w = temp_w`、`b = temp_b` | 第 2 步用到的 w 仍然是更新之前的 w |
| **非同时更新**（不正确） | 先 `w = w - α·∂J/∂w`，再 `b = b - α·∂J/∂b` | 执行第 2 步时 w 已经被换成新的值，算出的 b 与正确实现不同 |

把非同时更新这一版实现出来，结果大概也能跑，但它是另一种性质不同的算法。通常说到梯度下降，指的就是同时对参数做更新的那一版，实现时按同时更新来写。

### 3.3 学习率 α：每一步跨多远（p13）

α 决定梯度下降每一步跨出多远，也因此决定它能不能走到最低点。更新式始终是同一条：

```math
w := w - \alpha \frac{\partial J}{\partial w}
```

不同取值的结果：

- **α 太小**：能走到，但步数极多。
- **α 太大**：越过最低点，越走越远 学习率太大时，梯度下降可能一次次越过最低点，始终到不了最低点，甚至发散。
- **参数已经在最低点**：更新什么也不做。**参数一旦把你带到了局部最小值，后续的梯度下降步骤不会改变任何参数，得到解。**

#### 3.3.1 越接近最低点，步子会自己变小

再看一个起点离最低点较远的例子。α 取一个适当的固定值时，第一步落在曲线较陡的位置，跨出的距离比较大。落到新位置后，这里的曲线比上一点平缓，导数更小，所以下一次更新不会像第一步那么大。继续更新下去，斜率越来越接近 0，每一步都更短，参数最终停在最低点附近。
**即使学习率 α 始终保持在某个固定值上，越靠近最低点，导数越小，更新的幅度也会自动变小。**

### 3.4 线性回归的梯度下降：两个偏导公式与唯一的全局最小值（p14）

线性回归模型、平方误差成本函数、梯度下降算法，这三块此前是分开讲的；这段视频把它们拼在一起，用来训练一条拟合训练数据的直线。把 ∂J/∂w 和 ∂J/∂b 分别代进 w 和 b 的更新式，每一步都按这两个偏导改动参数：

```math
w := w - \alpha \frac{\partial J}{\partial w} \qquad b := b - \alpha \frac{\partial J}{\partial b}
```

其中 α 是学习率。

#### 3.4.1 两个偏导：直接可用的公式

```math
J(w,b) = \frac{1}{2m}\sum_{i=1}^{m}(f_{w,b}(x^{(i)}) - y^{(i)})^2
```

把 J(w,b) 分别对 w 和 b 求偏导，得到下面两个式子；用它们来实现梯度下降，模型就能训练起来。

```math
\frac{\partial J}{\partial w} = \frac{1}{m}\sum_{i=1}^{m}\left(f_{w,b}(x^{(i)}) - y^{(i)}\right) \cdot x^{(i)}
```

```math
\frac{\partial J}{\partial b} = \frac{1}{m}\sum_{i=1}^{m}\left(f_{w,b}(x^{(i)}) - y^{(i)}\right)
```

两个式子结构相同：都是 1/m 乘以所有样本上误差项的和，括号里的误差项是预测值减去实际值。**唯一的差别在末尾——对 b 求偏导的式子里没有乘 x⁽ⁱ⁾。**

#### 3.4.2 回到定义：1/2 起什么作用

先看对 w 的偏导，做法是把成本函数的定义原样代进偏导式：

1. 写出 J(w,b) 的定义：1/2m 乘以所有样本平方误差项之和。
2. 代入模型 f(x⁽ⁱ⁾) = wx⁽ⁱ⁾ + b。
3. 对 w 求偏导（partial derivative），化简后得到前面那个式子。

**成本函数里那个 1/2 就是为这一步准备的**：平方项求导时会带出一个因子 2，1/2 正好把它抵消掉，偏导写出来更简洁。这也是更早定义成本函数时特意加上 1/2 的原因。

> 🔑 这就是「成本函数为什么要除以 2」的答案——它与平方项求导时出现的因子 2 相消。

对 b 求偏导的推导步骤完全相同，写出来的结果也就是少了末尾 x⁽ⁱ⁾ 的那一版。

#### 3.4.3 线性回归不会陷入局部最小值

初始化 w 和 b 的位置不同，梯度下降可能停在这个局部最小值上，也可能停在另一个上。
线性回归配上平方误差成本函数时不会出现这种情况：它的形状是弓形的，**从来没有多个局部最小值，只有唯一的一个全局最小值**。这样的函数在术语里叫**凸函数**（convex function），弓形是它直观的形状。在凸函数上实现梯度下降有一个很好的性质：**只要学习率选得合适，就总会收敛到全局最小值。**
线性回归梯度下降时候，全部 m 个训练样本都被算进去，参数更新时看的是整批训练样本。这种做法叫**批量梯度下降**（batch gradient descent）。
