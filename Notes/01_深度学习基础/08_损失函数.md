# 08_损失函数

> 🧭 损失函数把“预测得好不好”变成可计算、可优化的数值。先按任务选合适的损失，再看它是否与标签表示和输出层匹配。

## 一、损失函数在训练中的位置

模型输出预测值，损失函数把预测与真实标签进行比较，训练过程再调整参数以减小损失。一个好用的训练目标通常需要：

- 能区分好预测与坏预测；
- 对模型参数变化有可用的梯度；
- 与任务类型和标签格式相符。

损失是训练用的目标；准确率、召回率等指标主要用于评估结果。指标变好不一定会让每一步训练都有平滑的梯度。

## 二、回归任务

回归输出连续数值。常见选择有均方误差和平均绝对误差。
均方误差会更重地惩罚较大的误差，也便于求导：

```math
L_{MSE}=\frac{1}{m}\sum_{i=1}^{m}(\hat y^{(i)}-y^{(i)})^2
```

有时会在前面乘 1/2，让求导后的常数更简洁；这不改变最优参数的位置。平均绝对误差对离群点相对不敏感，但在误差为 0 的位置不可导，实际实现会使用可处理的次梯度。

## 三、二分类任务

二分类模型通常输出正类概率 p，标签 y 为 0 或 1。二元交叉熵为：

```math
L_{BCE}=-\frac{1}{m}\sum_{i=1}^{m}
\left[y^{(i)}\log p^{(i)}+(1-y^{(i)})\log(1-p^{(i)})\right]
```

当真实标签为 1 时，模型把 p 预测得越接近 1，损失越小；真实标签为 0 时，p 越接近 0，损失越小。模型对错误类别越自信，惩罚通常越大。

## 四、多分类任务

多分类模型先给每个类别产生一个 logit，再用 softmax 转换成概率：

```math
p_k=\frac{e^{z_k}}{\sum_{j=1}^{K}e^{z_j}}
```

若真实类别用 one-hot 标签 y 表示，交叉熵为：

```math
L_{CE}=-\frac{1}{m}\sum_{i=1}^{m}\sum_{k=1}^{K}
y_k^{(i)}\log p_k^{(i)}
```

one-hot 标签只有正确类别对应的位置为 1，因此每个样本的损失等价于正确类别概率的负对数。二分类交叉熵是其二分类对应形式；不要把任务的类别数、标签编码与模型输出层混配。

## 五、实现时的数值稳定性

直接计算 e\^z 可能溢出。softmax 可以先减去同一样本中最大的 logit，再计算指数：

```math
p_k=\frac{e^{z_k-c}}{\sum_j e^{z_j-c}},\qquad c=\max_j z_j
```

分子、分母同时乘上同一个常数因子，概率不变，但数值范围更安全。实践中通常使用深度学习框架提供的 logits 版本损失函数，由框架合并 log-softmax 与交叉熵计算，避免先手动算概率再取对数。

## 六、损失与指标不要混为一谈

- **训练损失**：每个样本的误差如何聚合成优化目标。
- **准确率**：预测类别是否正确，适合类别较均衡的分类任务。
- **精确率 / 召回率**：关注误报或漏报，适合不同错误代价的场景。
- **F1**：精确率与召回率的折中汇总，不直接表达概率校准。

类别严重不平衡时，单看准确率可能会误导；可结合混淆矩阵、各类别指标与实际错误代价来评估。

> ⚠️ **先对齐三件事**：任务类型、模型输出、标签格式。比如多分类 logits 应交给匹配的多分类损失，不要把已经 softmax 的概率误当成 logits 再输入。

> ✅ 回归常用 MSE / MAE；二分类常用 BCE；多分类常用 softmax 交叉熵。损失负责训练，评估指标负责观察任务表现。
