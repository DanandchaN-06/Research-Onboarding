# 07_前向传播与反向传播

> 🧭 承接 06《神经网络基础》：前向传播把输入变成预测，反向传播把预测误差变成每个参数的梯度。两者合起来，模型才知道怎样学习。

## 一、先分清前向与反向

- **前向传播**：按网络顺序计算每层的线性部分和激活值，得到预测。
- **损失计算**：比较预测与真实标签，得到一个标量损失。
- **反向传播**：从损失往回应用链式法则，计算每个参数对损失的影响，也就是梯度。
- **梯度下降**：拿梯度更新参数。

反向传播负责**算梯度**，梯度下降负责**改参数**。它们有关联，但不是同一件事。

## 二、从一个神经元看链式法则

设一个神经元先计算线性值，再经过 sigmoid 得到预测概率：

```math
z = wx + b,\qquad a = \sigma(z)
```

若使用二元交叉熵，标签为 y，损失为：

```math
L = -\bigl(y\log a + (1-y)\log(1-a)\bigr)
```

链式法则把复杂函数拆成一串局部导数。对 sigmoid 与二元交叉熵的组合，化简后有：

```math
\frac{\partial L}{\partial z}=a-y
```

因此：

```math
\frac{\partial L}{\partial w}=(a-y)x,\qquad
\frac{\partial L}{\partial b}=a-y
```

直觉上，预测 a 与标签 y 差得越多，参数收到的修正信号越大；输入 x 决定权重 w 的梯度大小。

## 三、多层网络的反向传播

记第 l 层的参数为 W\^\[l\]、b\^\[l\]，线性输出为 Z\^\[l\]，激活值为 A\^\[l\]。反向传播从输出层开始：

1. 先根据输出层激活函数和损失函数求 dZ\^\[L\]。对 sigmoid + 二元交叉熵或 softmax + 多类交叉熵，常见结果是预测减标签。
2. 用 dZ\^\[l\] 和上一层激活值 A\^\[l-1\] 求这一层的权重梯度。
3. 将误差信号传回上一层，再乘上该层激活函数的导数。
4. 重复直到输入端。

把 m 个样本合成矩阵时，常用的梯度写法是：

```math
dW^{[l]}=\frac{1}{m}dZ^{[l]}(A^{[l-1]})^T,\qquad
db^{[l]}=\frac{1}{m}\sum_{i=1}^{m}dZ^{[l](i)}
```

继续向前传递的误差信号为：

```math
dA^{[l-1]}=(W^{[l]})^T dZ^{[l]},\qquad
dZ^{[l-1]}=dA^{[l-1]}\odot g'^{[l-1]}(Z^{[l-1]})
```

这里的平均是对一个批次中的样本求平均；转置和维度必须与前向传播的矩阵乘法相匹配。

## 四、保存什么、为什么能高效

反向计算会用到前向传播得到的 Z 和 A，所以训练时通常缓存每层的中间结果。随后沿计算图反向走一遍，局部导数逐层相乘，并复用矩阵运算。
这就是反向传播高效的原因：它不会为每个参数重新跑一遍完整模型，而是一次反向遍历就能得到所有参数的梯度。

## 五、梯度如何用于更新

最简单的梯度下降更新为：

```math
W^{[l]}:=W^{[l]}-\alpha dW^{[l]},\qquad
b^{[l]}:=b^{[l]}-\alpha db^{[l]}
```

α 是学习率。反向传播给出“往哪边改、改动对损失有多敏感”，学习率决定每次走多远。

## 六、常见错误与检查

- 忘记激活函数导数，误差信号就无法正确传回前一层。
- 把 W 的转置方向写反，或让批次维度混入求和维度。
- 漏掉对批次大小 m 求平均，梯度大小会随批次大小变化。
- 只检查梯度数值、不检查形状；每层的 dW、db 应与对应参数同形状。
- 训练代码里先更新参数，再用已更新的参数计算同一轮的其他梯度。

小网络可以用有限差分做梯度检查：对某个参数轻微增加、减少 ε，比较数值近似梯度与反向传播梯度是否接近。它适合调试，不适合直接替代反向传播训练。

> ✅ **记住这条链**：前向算预测 → 损失衡量错误 → 反向传播算梯度 → 优化器更新参数。
