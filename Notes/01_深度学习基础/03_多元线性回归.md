## 一、多元线性回归模型

### 1.1 从单特征到多特征

原来的线性回归只有一个输入特征：用房屋**面积** $`x`$ 预测价格 $`y`$，模型是 $`f_{w,b}(x) = wx + b`$。
如果同时知道**卧室数量**、**楼层数**、**房龄（年）**，可用于预测的信息就更多。这四个量一起构成模型的输入：

- 面积（$`x_1`$）
- 卧室数量（$`x_2`$）
- 楼层数（$`x_3`$）
- 房龄（$`x_4`$，单位为年）

### 1.2 多特征记号系统

下表回答的是：多特征下每个符号各自指什么（以四特征房屋例子为准）。

| **记号** | **含义** | **四特征例子** |
| --- | --- | --- |
| $`x_j`$ | 第 $`j`$ 个特征，$`j`$ 从 1 取到 $`n`$ | $`x_1`$ 面积、$`x_2`$ 卧室数量、$`x_3`$ 楼层数、$`x_4`$ 房龄 |
| $`n`$ | 特征的总数 | 4 |
| $`x^{(i)}`$ | 第 $`i`$ 个训练样本的全部特征，是一个含 $`n`$ 个数的向量 | $`x^{(2)} = [1416, 3, 2, 40]`$ |
| $`x_j^{(i)}`$ | 第 $`i`$ 个训练样本的第 $`j`$ 个特征值 | $`x_3^{(2)} = 2`$，即第 2 个样本的楼层数 |

> ⚠️ **上标是样本编号，下标是特征编号**，两者不可混淆。$`x^{(2)}`$ 是「第 2 个样本的全部特征」（一串数），$`x_2`$ 是「第 2 个特征」（一列数）。

把向量的数值横着写成一排，得到的是**行向量**；竖着写则是**列向量**。两者的区别在本课程里不重要。为提醒某个符号表示的是向量而非单个数字，可以在它上方画一个小箭头——**箭头只是可选标记，不画不影响含义**。

### 1.3 模型表达式与参数含义

多个特征进入模型的方式是：**每个特征各乘一个权重，再全部相加，最后加上常数项**。

```math
f_{\mathbf{w},b}(\mathbf{x}) = w_1x_1 + w_2x_2 + w_3x_3 + w_4x_4 + b
```

特征有 $`n`$ 个时，式子写成 $`w_1x_1 + w_2x_2 + \cdots + w_nx_n + b`$。
把四个特征代进去，得到一个具体的价格模型（价格以千美元为单位）：

```math
价格 = 0.1 \times x_1 + 4 \times x_2 + 10 \times x_3 - 2 \times x_4 + 80
```

下表回答的是：每个参数在「输入变一个单位、价格变多少」这个读法下各是什么。

| **参数** | **对应的输入变化** | **价格变化** |
| --- | --- | --- |
| $`b = 80`$ | 所有特征都为 0 时的基准价格 | 约 80,000 美元 |
| $`w_1 = 0.1`$ | 面积每增加 1 个单位 | 增加 0.1 千美元，约 100 美元 |
| $`w_2 = 4`$ | 卧室每增加 1 间 | 增加 4,000 美元 |
| $`w_3 = 10`$ | 楼层每增加 1 层 | 增加 10,000 美元 |
| $`w_4 = -2`$ | 房龄每增加 1 年 | 减少 2,000 美元（权重为负数） |

这组系数只是用来说明参数含义的一种可能模型，不是唯一解。

### 1.4 用点积把模型写短

把所有权重收进一个数字列表 $`\mathbf{w} = [w_1, w_2, \cdots, w_n]`$，这样的列表在数学上叫**向量**；特征同样写成向量 $`\mathbf{x} = [x_1, x_2, \cdots, x_n]`$。$`b`$ 仍然是一个单独的数字，向量 $`\mathbf{w}`$ 和数字 $`b`$ 一起构成模型的参数。

```math
f_{\mathbf{w},b}(\mathbf{x}) = \mathbf{w} \cdot \mathbf{x} + b
```

这里的「$`\cdot`$」表示线性代数中的**点积**：两个向量的对应项分别相乘再求和，$`\mathbf{w}\cdot\mathbf{x} = w_1x_1 + w_2x_2 + \cdots + w_nx_n`$，最后再加上 $`b`$。
把点积展开，得到的正是前面那个逐项相加的式子，**两种写法完全等价**；点积形式的意义在于用更少的字符表达同一个模型。

### 1.5 模型的名称

- **multiple linear regression（多元线性回归）** — 有多个输入特征的线性回归。
- **univariate regression（一元线性回归）** — 只有一个特征的版本。
- **multivariate regression** — 这个词指另一种东西，本课程不使用。

> 💡 「多元线性回归」的「元」指的是**特征个数**，不是样本个数。别与 multivariate regression 混用。

## 二、向量化

### 2.1 为什么需要向量化

实现学习算法时，向量化同时改变代码的长度和运行方式：

- **代码更短** — 同一处计算，向量化写法需要的代码明显更少。
- **运行更高效** — 向量化代码可以直接使用现代数值线性代数库，并用上 GPU 这类硬件。

### 2.2 记法从 1 数起，Python 数组从 0 数起

这一节用到的量是参数 $`\mathbf{w}`$、$`b`$ 和输入 $`\mathbf{x}`$。$`\mathbf{w}`$ 有三个数，所以 $`n = 3`$；$`b`$ 是一个数；$`\mathbf{x}`$ 有三个特征。
线性代数里的索引从 1 开始计数，第一个值写作 $`w_1`$、$`x_1`$。在 Python 中，这些量用 NumPy 定义成数组，取值写法随之改变。
下表回答的是：同一批数值在两种记号下分别怎么取。

| **语境** | **第 1 个值** | **第 2 个值** | **第 3 个值** | **计数起点** |
| --- | --- | --- | --- | --- |
| 线性代数记法 | $`w_1`$、$`x_1`$ | $`w_2`$、$`x_2`$ | $`w_3`$、$`x_3`$ | 1 |
| Python 数组 | `w[0]`、`x[0]` | `w[1]`、`x[1]` | `w[2]`、`x[2]` | 0 |

### 2.3 计算预测值的三种写法

**做法一：逐项写出**
每个参数 $`w`$ 乘以对应的特征 $`x`$，把乘积相加，最后加上 $`b`$：

```python
f = w[0]*x[0] + w[1]*x[1] + w[2]*x[2] + b
```

$`n = 3`$ 时这样写还过得去；如果 $`n`$ 是 100 或 10 万，逐项写出来对人和对计算机都不高效。
**做法二：for 循环**
数学上一个求和记号就够了：$`f = \sum_{j=1}^{n} w_j x_j + b`$，求和范围包含 $`n`$。

```python
f = 0
for j in range(0, n):
    f += w[j] * x[j]
f = f + b
```

`range(0, n)` 让 $`j`$ 从 0 走到 $`n-1`$（不含 $`n`$），显式写出 0 是为了与 Python 数组索引对齐。这个写法比逐项写出省事，但**仍然没有用上向量化，效率不高**。
**做法三：用 `np.dot` 向量化**
数学关系不变：$`f`$ 等于 $`\mathbf{w}`$ 与 $`\mathbf{x}`$ 的点积再加 $`b`$。

```python
f = np.dot(w, x) + b
```

`np` 是 NumPy 的简称；`np.dot` 实现的是向量 $`\mathbf{w}`$ 与 $`\mathbf{x}`$ 之间的数学点积，末尾再加上 $`b`$。
下表回答的是：三种写法在代码形态、是否向量化与限制上的差别。

| **写法** | **代码形态** | **是否向量化** | **前提或限制** |
| --- | --- | --- | --- |
| 逐项写出 | $`w_0x_0 + w_1x_1 + \cdots + b`$ 全部写出来 | 否 | $`n`$ 稍大就难以书写 |
| for 循环 | 循环内累加 `w[j]*x[j]`，循环结束再加 $`b`$ | 否 | 顺序计算，效率不高 |
| `np.dot` | `f = np.dot(w, x) + b` | 是 | 需要把 $`\mathbf{w}`$、$`\mathbf{x}`$ 组织成向量并使用 NumPy |

### 2.4 向量化为什么快

**非向量化（按索引逐个计算）**：第一个时间步处理索引 0 处的值，下一个时间步才计算索引 1 对应的值，依此类推直到索引 15。每个时间步完成一次计算，前后相继。
**向量化**：硬件可以一次取到向量 $`\mathbf{W}`$ 和 $`\mathbf{X}`$ 的全部值，在单步之内把每一对相乘，这些乘法**同时并行进行**；随后再用专用硬件把这 16 个数一次加总，无需逐个做加法。
放到梯度下降的一次参数更新上看：假设要更新 16 个权重 $`W_1`$ 到 $`W_{16}`$，更新规则是

```math
W_j \leftarrow W_j - 0.1 \times d_j
```

其中 $`j`$ 从 1 到 16（代码索引是 0 到 15），$`d_j`$ 是对应的导数，$`0.1`$ 是学习率。

```python
# 循环写法
for j in range(0, 16):
    w[j] = w[j] - 0.1 * d[j]

# 向量写法
w = w - 0.1 * d
```

向量写法把整批更新交给并行处理硬件：硬件取到 $`\mathbf{w}`$ 的全部 16 个值，同时减去 $`0.1`$ 乘 $`\mathbf{d}`$ 中对应的 16 个值，再把结果一并写回 $`\mathbf{w}`$，所有运算落在同一步里。

> ⚠️ 只有 16 个特征时，这种提速并不夸张。**特征数达到成千上万、训练集也很大时，差别才会非常明显**——向量化是后期规模上来后的性能保障。

## 三、多元线性回归的梯度下降

### 3.1 参数收进向量，模型与代价函数一起改写

把所有 $`w`$ 收进一个向量 $`\mathbf{w}`$，长度是 $`n`$；$`b`$ 仍然是一个数字。整个模型的参数就是「向量 $`\mathbf{w}`$ + 数字 $`b`$」。

- 模型：$`f_{\mathbf{w},b}(\mathbf{x}) = \mathbf{w} \cdot \mathbf{x} + b`$。
- 代价函数：原来看成 $`w_1`$ 到 $`w_n`$ 以及 $`b`$ 的函数，现在直接写成 $`J(\mathbf{w}, b)`$——输入是向量 $`\mathbf{w}`$ 和数字 $`b`$，返回一个数。

### 3.2 每个参数各有一条更新规则

梯度下降的算法结构没有变：重复更新每一个参数，让它减去学习率 $`\alpha`$ 乘以代价函数对该参数的导数。

```math
w_j := w_j - \alpha \frac{\partial J(\mathbf{w}, b)}{\partial w_j}, \quad j \text{ 取 } 1 \text{ 到 } n
```

```math
b := b - \alpha \frac{\partial J(\mathbf{w}, b)}{\partial b}
```

下表回答的是：单特征与 $`n`$ 个特征时，更新规则在「数量」和「内容」上差在哪。

| **情形** | **规则数量** | **导数项** |
| --- | --- | --- |
| 单特征 | $`w`$ 一条，$`b`$ 一条 | 代价函数对参数 $`w`$ 的导数 |
| $`n`$ 个特征 | $`w_1`$ 到 $`w_n`$ 各一条，加 $`b`$ 一条，共 $`n+1`$ 条 | 仍由预测值 $`f(\mathbf{x})`$ 减去目标值 $`y`$ 构成，只是 $`\mathbf{w}`$ 和 $`\mathbf{x}`$ 以向量形式参与运算 |

规则从 2 条变成 $`n+1`$ 条，但每条规则内部的算式形状保持不变。

### 3.3 正规方程：一次解出，但适用范围窄

求解 $`\mathbf{w}`$ 和 $`b`$ 还有另一条路，叫**正规方程法**（normal equation method）。它不需要迭代的梯度下降，而是借助高级线性代数库一次性把 $`\mathbf{w}`$ 和 $`b`$ 解出来。

- **只对线性回归有效** — 本课程里出现的其他算法上基本都用不上。
- **特征很多时很慢** — 特征数量一大，正规方程的计算就会变得很慢。

> 💡 正规方程是「知道有这回事」即可，本课程主线仍是梯度下降——它能扩展到后续的神经网络等模型。

## 四、让梯度下降跑得更快

### 4.1 特征缩放：为什么有用

先看一个直观入口：**特征取值的大小与对应权重的大小是配套的**。
例子还是房价预测，两个特征：$`x_1`$ 房屋面积（约 300 到 2000 平方英尺）、$`x_2`$ 卧室数量（0 到 5 间）。要预测的房子是 2000 平方英尺、5 间卧室，实际售价 500,000 美元。
下表回答的是：两组权重对同一套房给出的预测为何差别巨大。

| **权重取值** | **计算过程** | **结果** |
| --- | --- | --- |
| $`w_1 = 50, w_2 = 0.1, b = 50`$ | 面积项 $`50 \times 2000 = 100{,}000`$；卧室项 $`0.1 \times 5 = 0.5`$；加 50 | 第一项在数量级上压过其他项，预测相差很远 |
| $`w_1 = 0.1, w_2 = 50, b = 50`$ | $`0.1 \times 2000 = 200`$；$`50 \times 5 = 250`$；加 50 | 合计 500（千美元）= 500,000 美元，正好等于实际售价 |

规律是：**取值范围大的特征配小权重**（面积动辄以千计，权重更可能学成 0.1 这样的值）；**取值范围小的特征配大权重**（卧室数只有个位数，权重更可能学到 50）。

### 4.2 取值范围之差会把等高线拉扁

权重的合理尺度会落到代价函数的形状上：面积范围大，$`w_1`$ 的合理范围就很小（约 0 到 1）；卧室数范围小，$`w_2`$ 的合理范围反而很大（可以到 10 到 100）。把代价函数画成 $`w_1`$–$`w_2`$ 平面上的等高线，**两个方向的刻度相差两个数量级，等高线被拉成又高又窄的椭圆**。
在这种被拉长的代价函数上跑梯度下降，路径会在窄方向上反复折返，沿长轴方向却推进得很慢，需要经过很多次迭代才接近最小值，训练因此变慢。
处理办法是对特征做缩放变换，把取值范围重新拉到同一量级（$`x_1`$ 缩放到 0–1，$`x_2`$ 也缩放到 0–1）。缩放之后，两个特征取值的范围彼此可比，等高线**更接近圆形**，梯度下降能沿一条更直接的路线走到全局最小值，速度明显提升。

### 4.3 三种把特征缩放到相近范围的做法

以 $`x_1`$（300–2000）和 $`x_2`$（0–5）为例，三种做法都只用到特征自身的统计量。
下表回答的是：三种缩放方法的公式、所需统计量与缩放后的实际范围。

| **方法** | **公式** | **需要的统计量** | $`x_1`$ 缩放后 | $`x_2`$ 缩放后 |
| --- | --- | --- | --- | --- |
| 除以最大值 | $`x \div \max`$ | 最大值 | 0.15 到 1 | 0 到 1 |
| 均值归一化 | $`(x - \mu) \div (\max - \min)`$ | 均值 $`\mu`$ 与取值范围 | −0.18 到 0.82 | −0.46 到 0.54 |
| z-score 标准化 | $`(x - \mu) \div \sigma`$ | 均值 $`\mu`$ 与标准差 $`\sigma`$ | −0.67 到 3.1 | 约 −1.6 到 1.9 |

- **除以最大值**：$`x_1`$ 除以 2000、$`x_2`$ 除以 5。$`x_1`$ 的最小值 300 大于 0，所以下界没落在 0 上。
- **均值归一化**：$`x_1`$ 的 $`\mu_1 = 600`$，按 $`(x_1-600)\div(2000-300)`$ 算；$`x_2`$ 的 $`\mu_2 = 2.3`$，按 $`(x_2-2.3)\div(5-0)`$ 算。缩放后的特征**围绕 0 分布**，负值正值都会出现，通常落在 −1 到 1。
- **z-score 标准化**：$`x_1`$ 的 $`\sigma_1 \approx 450`$，按 $`(x_1-600)\div450`$ 算；$`x_2`$ 的 $`\sigma_2 \approx 1.4`$，按 $`(x_2-2.3)\div1.4`$ 算。标准差衡量数据相对均值的分散程度，在正态分布里就是那个 $`\sigma`$；没接触过也不影响使用，按公式代入即可。

> ⚠️ 均值归一化和 z-score 标准化都以均值 $`\mu`$ 为中心，会产出负值；除以最大值则以 0 为下界（当最小值恰好为 0 时）。**不要把「除以最大值」也当成以 0 为中心**。

### 4.4 什么范围算合格

缩放后的特征大致落在 −1 到 1 附近比较理想，但这条界限**相当宽松**：落在 −3 到 3，或者 −0.3 到 0.3，都算可以接受，不必再处理。
下表回答的是：什么样的取值范围值得重新缩放。

| **情形** | **判断** |
| --- | --- |
| $`x_1`$ 落在 0 到 3 | 范围稍大，仍然没问题；想缩放可以顺手做一次 |
| $`x_3`$ 从 −100 到 100 | 量级过大，值得重新缩放 |
| $`x_4`$ 从 −0.001 到 0.001 | 数值过小，同样可以再调整一次 |
| $`x_5`$ 是体温这类特征，98.6 到 105，量级约 100 | 与其他特征差距明显，会让梯度下降变慢，缩放很可能有帮助 |

判断依据是**量级差距**：范围过大或数值极小的特征，重新缩放往往有用；落在宽松区间内的则可以放着不管。

> 💡 **重新缩放特征几乎从来不会带来坏处**，拿不准的时候直接做一遍就行。加上这一小步之后，梯度下降经常能跑得快很多。

### 4.5 检查梯度下降是否收敛

判断梯度下降是否收敛，看的是它有没有把参数带到代价函数接近全局最小值的位置。
把模型每次迭代后的代价 $`J`$ 记录下来，就得到一条**学习曲线**。它的纵轴是代价 $`J`$，横轴是**迭代次数**——注意与此前见过的图不同，那些图的横轴放的是单个参数 $`w`$ 或 $`b`$。
曲线上第 100 次迭代处的点，对应参数经过 100 次同步更新之后的取值；这一点的纵坐标就是这组参数下的 $`J(\mathbf{w},b)`$。
下表回答的是：学习曲线的三种形态各自说明什么。

| **曲线形态** | **含义** |
| --- | --- |
| 每次迭代都下降 | 梯度下降正常工作，$`J`$ 在每一次迭代后都应当下降 |
| 某次迭代后反而上升 | 通常意味着学习率 $`\alpha`$ 选得太大；也可能代码里存在错误 |
| 逐渐变平 | 下降到约 300、400 次之后幅度已经很小，说明基本收敛 |

学习曲线还能用来**决定何时停止训练**：事先很难知道需要多少次迭代，不同问题可能只要 30 次，也可能要 1000 次甚至 100000 次；画出曲线就能看出当前模型什么时候可以停。
**自动收敛检验**：令 $`\varepsilon`$ 表示一个很小的数（例如 0.001）。如果某次迭代后 $`J`$ 的下降量小于 $`\varepsilon`$，就判定已经收敛——这时学到的 $`\mathbf{w}`$ 和 $`b`$ 已接近 $`J`$ 能达到的最小值。

> ⚠️ 阈值 $`\varepsilon`$ 取多少合适**相当难判断**，所以实际中通常直接看学习曲线，把自动收敛检验放到一边。课程作者本人也更倾向于看曲线——曲线还能在梯度下降没正常工作时提前给出警告。

### 4.6 选择学习率 α

学习率选得合适时，算法会运行得好很多。两个方向的失败都很直接：**α 太小 → 跑得非常慢；α 太大 → 可能根本无法收敛**。
**α 过大时每次更新都越过最低点**：每一步按 $`w_1 := w_1 - \alpha \cdot (\text{导数项})`$ 更新。α 太大时这一步减去的量过多，参数被直接推过最低点、落到曲线另一侧；下一次更新再从那一侧跨回来，落点离最低点比上一次更远。更新一次次越过最低点，参数在两侧来回跳动并且越跳越远，代价也就逐轮上升。
把学习率换小一些，同样的更新步骤就会一步一步向最低点靠近，代价持续下降。
**更新式符号写反也会让代价一路上升**：

- 写成加号：$`w_1 := w_1 + \alpha \cdot (\text{导数项})`$，代价可能每轮持续上升。
- 写成减号：$`w_1 := w_1 - \alpha \cdot (\text{导数项})`$，这是更新式**应有**的形式。

**调试手段**：只要学习率**足够小**，代价函数应当在每一次迭代后都下降。

- **做法** — 梯度下降不工作时，先把 α 设成一个非常小的数，看代价是否每轮都下降。
- **判读** — 如果连这么小的 α 都做不到让代价每轮下降、反而有时上升，那通常说明代码里有 bug。
- **注意** — 取极小值的 α 只是调试手段，不是实际训练的选择：代价会稳定下降，但下降得很慢。

下表回答的是：从候选值里试出合适 α 的步骤。

| **步骤** | **做法** |
| --- | --- |
| 试值方式 | 从 0.001 开始，提高到约三倍得 0.003，再提高到约三倍得 0.01，按同样比例继续往上试 |
| 何时停下 | 一直试到既能找到一个明显太小的取值，也能找到一个明显太大的取值 |
| 最终选择 | 取最大的那个合理取值，或者略小于它的值 |

> 💡 先只跑少量迭代、把代价画成迭代次数的函数，再比较几个不同 α 的效果，比盲试效率高得多。

## 五、特征工程与多项式回归

### 5.1 特征工程：用对问题的理解设计特征

特征的选择会大幅影响学习算法的表现。在房价预测里，每个房子有两个特征：$`x_1`$ 临街宽度（frontage，房子正面那条边的长度）、$`x_2`$ 进深（depth）。
土地面积可以由临街宽度乘以进深算出来，而直觉上土地面积对房价的预测力更强。顺着这个思路，可以定义第三个特征 $`x_3 = x_1 \times x_2`$。
下表回答的是：两种特征用法对应的模型各自是什么。

| **方案** | **特征** | **模型** |
| --- | --- | --- |
| 直接用原始特征 | $`x_1`$ 临街宽度、$`x_2`$ 进深 | $`f_{\mathbf{w},b}(\mathbf{x}) = w_1x_1 + w_2x_2 + b`$（可能还算可用） |
| 把面积也加进来 | $`x_1`$、$`x_2`$，以及 $`x_3 = x_1 \times x_2`$ | $`f_{\mathbf{w},b}(\mathbf{x}) = w_1x_1 + w_2x_2 + w_3x_3 + b`$（可能更有效） |

多一个特征之后，模型可以选择 $`w_1`$、$`w_2`$、$`w_3`$ 的取值，**由数据来说明**：临街宽度、进深和面积这三者之中，哪一个才是预测房价最重要的因素。
把两个特征相乘、造出 $`x_3`$ 这一步，名字叫**特征工程**（feature engineering）：利用你对问题的知识或直觉，设计出新的特征。能得到什么取决于你手里有哪些洞见；比起只用一开始拿到的那两个特征，定义新特征有时能换来更好的模型。

### 5.2 多项式回归：同一个特征的不同次幂

用房屋面积预测价格时，模型里同时放入面积和面积的平方，得到的曲线**先随面积上升，到了大面积区间又回落下来**。这条回落的曲线与实际情况对不上：面积大的房子通常应该更贵。
换成三次函数，特征里多出面积的立方，曲线随面积增大**继续上升**，对数据的拟合也更好。
把原始特征取 2 次、3 次或任意次幂，用这些幂次构造新特征，这样的模型称为**多项式回归**。

```math
w_1 x + w_2 x^2 + w_3 x^3 + b
```

其中 $`x`$ 是房屋面积，三项分别对应面积、面积的平方和面积的立方，**每一项都带一个需要学习的参数**。

### 5.3 高次幂必须配特征缩放

特征取了高次幂之后，几个特征落在完全不同的数值区间里。面积取 1 到 1000 平方英尺时：
下表回答的是：同一个特征取不同次幂后的取值范围差了多少。

| **特征** | **取值范围** | **说明** |
| --- | --- | --- |
| 面积 $`x`$ | 约 1 – 1000 平方英尺 | 原始特征 |
| 面积的平方 $`x^2`$ | 约 1 – 1,000,000 | 上界是面积的约 1000 倍 |
| 面积的立方 $`x^3`$ | 约 1 – 1,000,000,000 | 上界是面积的约 1,000,000 倍 |

> ⚠️ 三个特征的取值范围相差几个数量级——**多项式回归里特征缩放不再是可选项，而是必须做**。这是本讲最容易忽略的一点。

### 5.4 平方根一类形式，以及特征该纳入哪些

除了高次幂，还可以在 $`x`$ 之外加入 $`x`$ 的平方根：

```math
w_1 x + w_2\sqrt{x} + b
```

对应的曲线随面积上升，但**增长逐渐变缓**，不会像二次曲线那样在大面积处回落。
选哪些特征、用哪种函数形式，本身是建模时要做的选择：可以纳入不同的特征组合，也可以比较含与不含某一项的模型；还有相应的算法可以帮助判断哪些特征该纳入、哪些该舍弃。**决定权在建模者手上，选得合适，得到的模型会更好。**

### 5.5 配套工具与使用边界

- **多项式回归实验**：用面积、面积的平方和面积的立方三个特征实现多项式回归，可以直接运行观察效果。
- **scikit-learn**：可选实验，演示如何用这个开源工具包实现线性回归，它是被许多从业者广泛使用的机器学习库。

> 💡 **使用边界**：需要自己理解并能够实现线性回归，**不能只把 scikit-learn 的函数当黑箱调用**；与此同时，它在实际机器学习工作方式中也有重要位置。

## 六、速查表

### 6.1 记号对照

下表回答的是：多特征下各记号的含义与示例。

| **记号** | **含义** |
| --- | --- |
| $`n`$ | 特征总数 |
| $`x_j`$ | 第 $`j`$ 个特征 |
| $`x^{(i)}`$ | 第 $`i`$ 个样本的全部特征（向量） |
| $`x_j^{(i)}`$ | 第 $`i`$ 个样本的第 $`j`$ 个特征值 |
| $`f_{\mathbf{w},b}(\mathbf{x}) = \mathbf{w}\cdot\mathbf{x} + b`$ | 多元线性回归模型 |
| $`J(\mathbf{w}, b)`$ | 代价函数，输入向量 $`\mathbf{w}`$ 与数字 $`b`$，返回一个数 |

### 6.2 索引起点对照

下表回答的是：同一批数值在数学记号与 Python 数组里怎么取。

| **语境** | **第 1 个** | **第 2 个** | **起点** |
| --- | --- | --- | --- |
| 线性代数 | $`w_1`$、$`x_1`$ | $`w_2`$、$`x_2`$ | 1 |
| Python | `w[0]`、`x[0]` | `w[1]`、`x[1]` | 0 |

### 6.3 特征缩放三法

下表回答的是：三种缩放方法的公式与所需统计量。

| **方法** | **公式** | **所需统计量** |
| --- | --- | --- |
| 除以最大值 | $`x \div \max`$ | 最大值 |
| 均值归一化 | $`(x - \mu) \div (\max - \min)`$ | 均值、取值范围 |
| z-score 标准化 | $`(x - \mu) \div \sigma`$ | 均值、标准差 |

### 6.4 常见问题对照

下表回答的是：训练中出现各种现象时对应的病因与处理。

| **现象** | **病因** | **怎么处理** |
| --- | --- | --- |
| 代价 $`J`$ 有时上升 | 学习率 $`\alpha`$ 太大（或代码有 bug） | 调小 $`\alpha`$；先排查更新式符号 |
| 代价每轮持续上升 | 更新式写成了加号 | 改回 $`w := w - \alpha \cdot (\text{导数项})`$ |
| 下降得极慢 | $`\alpha`$ 太小，或特征未缩放 | 适当增大 $`\alpha`$；做特征缩放 |
| 小 $`\alpha`$ 下代价仍不单调下降 | 代码实现有 bug | 取极小 $`\alpha`$ 做调试判据 |
| 等高线又高又窄、路径反复折返 | 特征取值范围相差悬殊 | 把各特征缩放到相近量级 |
| 多项式特征训练不稳 | 高次幂取值范围被拉开数量级 | 多项式回归**必须**做特征缩放 |

## 小结

> ✅ **一句话结论**：多元线性回归把单特征的 $`wx+b`$ 扩展成 $`\mathbf{w}\cdot\mathbf{x}+b`$——用 $`n`$ 个权重、一套上标下标记号与向量点积，把多个特征统一进同一个模型；训练上仍是梯度下降，只是规则从 2 条变成 $`n+1`$ 条；要让它跑得动，关键在三件事：**用向量化替代 for 循环**、**把各特征缩放到相近量级**（多项式回归里更是必须做）、按学习曲线与约三倍比例试出合适的 $`\alpha`$；必要时再通过特征工程与多项式回归构造更有预测力的特征。
