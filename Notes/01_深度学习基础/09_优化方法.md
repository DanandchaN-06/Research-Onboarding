# 09_优化方法

> 🧭 优化方法根据梯度调整模型参数。它们的核心区别在于：使用多少数据估算梯度，以及如何利用过去的梯度信息。

## 一、从梯度到参数更新

设所有参数合记为 θ，训练目标为 J(θ)。梯度指出损失增长最快的方向，因此最基本的更新沿负梯度方向：

```math
\theta_{t+1}=\theta_t-\alpha\nabla_\theta J(\theta_t)
```

α 是学习率。优化方法不会替你选对目标函数，也不能弥补错误的数据或标签；它决定如何沿当前梯度更新参数。

## 二、三种梯度估算方式

- **批量梯度下降**：每次用全部训练样本估计梯度。更新方向稳定，但数据很大时每一步成本高。
- **随机梯度下降（SGD）**：每次只用一个样本。更新便宜但噪声大，损失曲线起伏明显。
- **小批量梯度下降**：每步用一小批样本。它能并行利用 GPU，梯度噪声与计算效率之间通常更实用。

小批量大小增大时，显存和单步计算量也会增加；小批量太小则硬件并行效率可能下降。没有适用于所有任务的固定最佳值。

## 三、动量

动量对近期梯度做指数加权平均，再用平滑后的方向更新：

```math
v_t=\beta v_{t-1}+(1-\beta)g_t,\qquad
\theta_{t+1}=\theta_t-\alpha v_t
```

它能减弱方向来回震荡，并在梯度持续朝同一方向时加速前进。β 越大，平均使用的历史信息越多。

## 四、RMSProp 与 Adam

RMSProp 累积梯度平方的移动平均，并按各参数近期梯度规模调整步长：

```math
s_t=\beta s_{t-1}+(1-\beta)g_t^2,\qquad
\theta_{t+1}=\theta_t-\alpha\frac{g_t}{\sqrt{s_t}+\epsilon}
```

Adam 同时维护梯度的一阶移动平均和平方梯度的二阶移动平均，并在训练初期进行偏差修正。它把动量与自适应步长结合起来，常作为深度学习的起始选择；具体任务仍需观察验证集表现。

## 五、学习率与调度

学习率过大可能在最低点附近来回跳动，甚至发散；过小则训练很慢。常见做法：

1. 先用保守的学习率启动，检查损失是否下降；
2. 观察训练与验证曲线，再逐步调整；
3. 训练后期按计划降低学习率，帮助参数稳定收敛；
4. 若损失突然变成 NaN 或无穷大，先检查学习率、输入尺度和数值计算。

学习率调度包括固定步数衰减、余弦衰减和基于验证指标的平台期衰减。选择时要记录实际学习率，保证实验可复现。

## 六、如何选优化器

- 小规模教学实现可从批量梯度下降或小批量 SGD 开始，方便观察更新原理。
- 大多数深度网络可先试 Adam，再根据任务和验证表现与 SGD + momentum 比较。
- 不要只比较训练损失；过拟合时训练损失更低，并不代表模型泛化更好。
- 比较方法时固定数据划分、预处理和训练预算，一次只改变少数因素。

> ✅ **实用起点**：小批量训练 + 合理初始化 + Adam 或 SGD with momentum；优先确认学习率和输入尺度，再做细调。
