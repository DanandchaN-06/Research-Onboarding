## 一、课程定位与视觉智能简史

本节由斯坦福计算机科学系**李飞飞（Fei-Fei Li）**教授主讲，本学期她与 **Ehsan Adeli 教授**及研究生 **Zane Durante** 联合授课。

### 1.1 三层包含关系

如果把人工智能看作一个大圈，计算机视觉是其中不可或缺的一块；机器学习是解决 AI 问题最重要的工具之一，而深度学习是过去十余年间机器学习内部的重大革命，其核心是一类叫**神经网络**的算法。
下表回答的是「AI、机器学习、深度学习、计算机视觉四者是什么关系」。

| 概念 | 在体系中的位置 | 本课的说法 |
| --- | --- | --- |
| 人工智能（AI） | 最大的圈，跨学科大领域 | 涉及数学、神经科学、计算机科学、心理学、物理学、生物学 |
| 机器学习 | AI 的子集，主要工具 | 又称统计机器学习 |
| 深度学习 | 机器学习的子集 | 一组以神经网络为核心的算法技术 |
| 计算机视觉 | AI 的子集，与深度学习高度交叉 | 「不仅是智能的一部分，更是智能的基石」 |

### 1.2 视觉是智能的基石

李飞飞反复强调：**视觉不仅是智能的一部分，更是智能的基石**——破解视觉智能的奥秘，就是在破解智能本身的奥秘。她也由此希望不同专业背景的学生都来听这门课，因为 AI 问题不全是工程问题，还有大量与人和社会相关的问题。人类尤其依赖视觉：**大脑皮层中约有半数的细胞参与视觉处理**。

### 1.3 视觉智能发展速览

从寒武纪到深度学习革命，关键里程碑如下。
下表回答的是「计算机视觉与深度学习是如何一步步走到今天的」。

| 时间 | 里程碑 | 意义 |
| --- | --- | --- |
| 约 5.4 亿年前 | 寒武纪大爆发，眼睛出现 | 感官让生命从被动代谢转为主动适应，驱动智能进化 |
| 1959 | Hubel 与 Wiesel 的猫视觉皮层实验 | 发现神经元有独立感受野、视觉通路分层（1981 年获诺奖） |
| 1963–1966 | Larry Roberts 首篇 CV 博士论文、MIT 暑期视觉项目 | 计算机视觉作为学科的开端 |
| 1970s | David Marr 的视觉计算层次 | 原始草图 → 2.5D 草图 → 3D 表征；视觉是从二维恢复三维的不适定问题 |
| 1980s | 第一次 AI 寒冬 | 只有边缘与草图，热情与资金大幅缩水 |
| 1980 | 福岛邦彦的 Neocognitron | 手工设计的分层网络，工程壮举 |
| 1986 | 反向传播 | 用链式法则自动调参，理论上的重大突破 |
| 1990s | Yann LeCun 的 LeNet | 首个真正落地：部署到邮局与银行读取手写数字 |
| 2000s 初 | ImageNet（约 1500 万张图、2.2 万个类别） | 确立「数据是头等公民」，创办 ILSVRC 挑战赛 |
| 2012 | AlexNet 赢得 ILSVRC | 错误率几乎减半，标志现代 AI 复兴与深度学习革命起点 |

AlexNet 与 32 年前的 Neocognitron 结构差别不大，真正的变量只有两个：**反向传播**与**数据**。此后**算法、数据、算力**三股力量汇聚，视觉识别迅速扩展到检测、分割、视频理解、医学影像、图像描述、生成式视觉（GAN → 扩散模型 → Midjourney）、三维视觉与具身智能体。
与此同时也要看到另一面：数据带着人类偏见，人脸识别等算法会继承这些偏见；而视觉仍有大量未解之处——人类的情感、好奇心与幽默感，今天的计算机视觉还远做不到。

第 1 讲给出了整门课的大纲：深度学习基础、感知与理解视觉世界、重建并与视觉世界交互三大主题，课程末尾还会讨论以人为本的 AI 伦理议题。本讲覆盖大纲中的前三项基础内容：

课程的目标是先从最基础的积木搭起，一步步走向卷积神经网络。本讲的路线是：先定义图像分类任务 → 讲最近邻 / kNN 这个最简单的分类器（顺带建立「超参数」和「数据集划分」的概念）→ 再讲线性分类器 → 最后引出损失函数与最优化，为下一讲做铺垫。

### 3.2 图像分类的形式化定义

图像分类（Image Classification）是计算机视觉的核心任务：

> 给定一张图像，以及一组预先定义好的类别标签（如狗、猫、卡车、飞机……），系统的任务是为这张图像分配**其中一个**标签。

对人类而言这几乎不费吹灰之力——我们的认知系统天生擅长此事，看一眼就能理解整张图并给出标签。但一旦要写程序让计算机读懂这张图，事情就完全不同了。

### 3.3 语义鸿沟：人眼所见 vs 机器所见

机器眼中的图像是一个**三维张量**（更宽泛地说就是张量数据结构）。一张分辨率 $`800 \times 600`$ 的彩色 RGB 图，每个像素有红、绿、蓝三个通道，因此是一整个 $`800 \times 600 \times 3`$ 的张量，共 144 万个数字，每个数字取值在 0 到 255 之间（8 bit）。
为什么是 0–255？因为图像的色彩标准有很多，但最常用的是 RGB 24 位格式：红、绿、蓝三个通道每个通道各占 8 bit（有时还有 Alpha 透明通道，变成 32 位）。$`2^8 = 256`$，所以单通道取值范围就是 0–255。
下表回答的是：**「人看到的图像」和「机器看到的图像」差别到底在哪里？**

| 维度 | 人类视角 | 机器视角 |
| --- | --- | --- |
| 表示形式 | 一个语义概念（「一只猫」） | $`H \times W \times 3`$ 的整数张量 |
| 数值范围 | 无所谓 | 每通道 0–255（8 bit） |
| 移动相机后 | 还是同一个物体 | 144 万个像素值全部改变，是一个全新的数据点 |
| 整体评价 | 一眼识别 | 存在巨大的 **Semantic Gap（语义鸿沟）** |

## 四、图像分类的七大难点

课程以「猫」为例逐个列举了真实图像数据中的变化与挑战。这些挑战共同决定了：一个好的图像分类模型必须在对这些变化保持不变性的同时，仍然对类别之间的差异保持敏感。
下表回答的是：**图像分类到底难在哪、每一类难点具体指什么？**

| 难点 | 英文术语 | 课程中的说明 |
| --- | --- | --- |
| 视角变化 | Viewpoint variation | 相机稍微平移一下，即使猫一动不动，$`800 \times 600 \times 3`$ 里每一个像素值都会变，但在人看来毫无区别 |
| 光照变化 | Illumination | RGB 像素值取决于表面材质、颜色和光源；同一只猫在暗处和阳光下数字表现完全不同 |
| 尺度变化 | Scale variation | 物体在图中的大小不同。注意：单纯的**图像分辨率**通常不是关键，因为我们会把图像尺寸归一化；真正的问题是物体本身的尺度差异 |
| 形变 | Deformation | 猫的身体非常柔软、容易变形；而现有算法通常是逐步构建的、先检测物体再识别，所以形变是主要挑战 |
| 遮挡 | Occlusion | 有时只能看到尾巴和一点疑似爪子的部分，人类靠上下文判断「沙发上大概率是猫」，算法却容易误判成老虎 |
| 背景杂乱 | Background clutter | 目标物体可能与背景融为一体，难以分离 |
| 类内差异 | Intra-class variation | 猫有各种体型、颜色、花纹甚至品种，本质都是猫，但对机器来说区分这些差异并不容易 |

还有一个贯穿性的挑战：**上下文（Context）**。如果算法只看局部像素、不看上下文，很容易把右图那只猫误判成老虎或其他动物；而结合「客厅沙发」这个上下文和阴影信息，就能正确分类。
需要说明的是：**如今的 classifier 已经做得相当出色**，这得益于 ImageNet 以及后续一系列工作建立了更大规模的基准，让我们能训练更大规模的模型，从而真正实现对图像中物体的识别。

## 五、从规则方法到数据驱动方法

### 5.1 为什么图像分类没法硬编码

如果你上过传统的算法与数据结构课，比如学排序算法，任务通常有清晰的流程图：if/else 分支、循环等结构，步骤明确、易于检验，照着写出来就能得到一个排序算法。
但面对图像、面对「理解视觉世界」这件事，这套方法行不通——你没法靠硬编码的步骤来给图像分类。

### 5.2 早期「边缘 + 角点」式的规则尝试

历史上确实有人做过尝试，有论文试图明确提出识别物体的算法步骤，其中一种思路是：

1. 第一步做**边缘检测（edge detection）**，找出图像里的边缘；
2. 生成各种模式之后再去观察哪些模式是重要的，比如**角点（corner）**；
3. 从角点周围提取特征，或者统计特定类型角点的数量；
4. 再根据这些特征做判断，把它映射到输出类别。

这种方法在某些变化非常有限的图像类型上取得了一些成功，但存在两个致命问题：

- **难以扩展**：你得为每一个想识别的对象都单独制定规则和各种细节；
- **费工费时**：为每一种对象找出对应的逻辑本身就很费功夫。

结论：**基于「制定逻辑和流程」来检测对象或分类图像的算法，效果并不理想。**

### 5.3 数据驱动方法的三步流程

机器学习带来了一种新范式——数据驱动（data-driven）方法，它定义了一套包含三个步骤的流程：

1. **收集数据集**：收集图像数据及其标签。如果想识别某类特定对象，可以从互联网上寻找数据集或单个数据点，从每个实例中生成大量样本。10–20 年前人们正是用互联网上的搜索引擎和图像搜索引擎来建立这类数据集的。
2. **训练分类器**：用机器学习算法训练分类器，本质上是构建一个函数——它接收训练数据中的图像及其对应标签，建立起把图像和标签关联起来的模型。
3. **在新图像上评估**：实现一个 `predict` 函数，接收模型和不属于训练集的测试图像，预测标签并作为输出返回。

下表回答的是：**规则方法和数据驱动方法的核心差异是什么？**

| 对比项 | 规则方法 | 数据驱动方法 |
| --- | --- | --- |
| 知识来源 | 人工编写的 if/else 规则与流程 | 带标签的训练数据集 |
| 典型步骤 | 边缘检测 → 角点检测 → 特征提取 → 映射类别 | 收集数据 → 训练模型 → 预测评估 |
| 可扩展性 | 每新增一类就要重写规则 | 换数据集即可 |
| 课程评价 | 效果不理想 | 本讲与全课采用的方法 |

## 六、最近邻分类器

### 6.1 基本思想与统一 API

最近邻分类器（Nearest Neighbor Classifier）是最简单的分类形式。它有两个函数：

- **训练函数**：把所有数据和标签都记下来，基本就是把所有东西存在内存里，除此之外什么都没做；
- **预测函数**：去找训练集中最像的那张图片，把它的标签输出出来。

所有分类器在课程里都遵循同一套 API：`train(X, y)` 接收数据与标签，`predict(X)` 接收新数据并输出预测标签。

### 6.2 L1 距离（曼哈顿距离）

要判断「最像」，就需要一个**距离函数**：输入两张图，逐像素一对一地比较，算出一个代表相似程度的数值。最常用的一种是 **L1 距离**：把所有像素差值的绝对值加起来。

```math
d_1(I_1, I_2) = \sum_{p} \left| I_1^p - I_2^p \right|
```

其中求和遍历所有像素。把两张图逐像素相减、再把差值加起来，就得到这两张图之间的距离。这是最基础的距离算法，但在很多场景下非常实用，本课程后面还会反复用到 L1 以及其他距离度量。

### 6.3 用 NumPy 实现最近邻

借助 Python 和 NumPy 等库，`predict` 函数其实四行核心代码就能搞定：算出每个测试样本与训练样本的距离 → 找最小值 → 输出最小索引对应的标签。

```python
import numpy as np

class NearestNeighbor(object):
    def __init__(self):
        pass

    def train(self, X, y):
        """X 是 N x D，每行一个样本；y 长度为 N。训练 = 把数据记住"""
        self.Xtr = X
        self.ytr = y

    def predict(self, X):
        """X 是 N x D，每行一个待预测样本"""
        num_test = X.shape[0]
        Ypred = np.zeros(num_test, dtype=self.ytr.dtype)

        for i in range(num_test):
            # L1 距离：逐像素差的绝对值之和
            distances = np.sum(np.abs(self.Xtr - X[i, :]), axis=1)
            min_index = np.argmin(distances)      # 距离最小的训练样本下标
            Ypred[i] = self.ytr[min_index]        # 把它的标签交出来

        return Ypred
```

### 6.4 复杂度失衡：训练 O(1)、预测 O(N)

假设训练数据里有 $`N`$ 个样本，用大 $`O`$ 符号表示计算复杂度：

- **训练复杂度**：$`O(1)`$：我们什么都没做，没有移动数据，只是把副本存进内存，常数时间即可完成。
- **预测复杂度**：$`O(N)`$：对每个测试图像，都要与所有 $`N`$ 个训练图像算一遍距离，至少是 $`N`$ 量级的操作。

这其实非常糟糕。课程里打了个比方：这就像你每次问 ChatGPT 一个问题，它都要去全网比对所有可能的答案，花上好几年才把结果返回给你——面对需要扩展的简单问题，这招根本行不通。
下表回答的是：**最近邻的复杂度分配为什么是「反的」、理想情况应该是什么样？**

| 阶段 | 最近邻分类器 | 我们真正想要的（如深度网络） |
| --- | --- | --- |
| 训练 | $`O(1)`$，只是存数据 | 慢一点没关系，可以离线完成 |
| 预测 / 测试 | $`O(N)`$，要与每个训练样本比较 | 必须快（单次矩阵乘法级别） |
| 空间 | 要保存整个训练集 | 训练完可丢弃训练集，只留参数 |

当然，为了让最近邻变快，社区做了很多努力（近似最近邻 ANN、GPU 加速等），但这超出了本课程的范围。

### 6.5 决策边界与异常值问题

把二维空间可视化来看：假设有红、蓝、绿、紫、黄五类，每个点是一类中的一个训练样本，空间被划分成若干区域，区域内的颜色代表该位置最近的邻居是谁——这就是 **1-最近邻（1-NN）** 算法划分空间的方式。
问题立刻显现：如果某个黄点正好被一堆绿点包围（它很可能是异常值或噪声，而这种情况在真实问题中很常见），那么因为它只用了「一个」最近邻，中间就会形成一大块不该存在的黄色区域。

## 七、k 最近邻分类器（kNN）

### 7.1 多数投票

为了提高**鲁棒性**，可以增加最近邻的数量，这就变成 **k 最近邻算法（k-Nearest Neighbor, kNN）**：不再只选一个，而是选 $`k`$ 个点或样本，然后通常采用**多数投票法（majority vote）**来决定任意测试样本的标签。$`k=1`$ 时就退化为最近邻。

### 7.2 白色区域：模糊地带的数据收集信号

$`k>1`$ 后可视化中会出现一些**白色区域**——在这些区域里，来自不同类别的邻居样本数量相等（例如来自三个不同类别各若干票），因此无法确定该样本的标签，只能随机选一个。
课程强调了一个很实用的观点：**这些白色模糊区域恰恰是最值得去收集更多数据的地方**。当你在自己的问题上构建出这个空间并观察它时，白色区域就标示了「数据不足、决策模糊」的位置。同理，如果你可视化样本或特征后发现某些区域根本没什么好样本、或者存在奇异点，就应该去该空间区域的同一位置寻找更多样本。

## 八、距离度量的选择：L1 vs L2

### 8.1 两种距离的定义与可视化

除了 L1（绝对值之和，也叫**曼哈顿距离**），另一个常用的距离函数是 **L2（欧氏距离）**：算的是差值的平方，求和之后再开方。

```math
d_2(I_1, I_2) = \sqrt{\sum_{p} \left( I_1^p - I_2^p \right)^2}
```

可视化上：L1 距离下，一个**正方形**边框上所有点到中心的距离都相等；L2 距离下，一个**圆**上每个点到圆心的距离都相等。这种可视化能帮我们直观理解两种度量的差异。
下表回答的是：**L1 和 L2 距离在性质上有什么区别、什么时候该选哪个？**

| 对比项 | L1（曼哈顿距离） | L2（欧氏距离） |
| --- | --- | --- |
| 定义 | 绝对差之和 | 平方差之和再开方 |
| 等距线形状 | 正方形（菱形） | 圆 |
| 对坐标轴旋转 | **敏感**：旋转特征后等距方框的形状和距离数值都会变 | **不敏感**：旋转后距离完全不变 |
| 特征有明确含义时 | 更好：形状能基于特征保留并强化距离 | 可用 |
| 特征比较随意时 | 更合理的默认选择 | 同样可用 |

### 8.2 为什么 L1 对坐标旋转敏感

在二维可视化中，$`x`$ 和 $`y`$ 其实就是两个**特征**（比如两个像素值）。如果旋转特征轴、也就是换用其他类型的特征：

- L1 的等距方框会变形，距离数值随之改变；
- L2 的圆旋转后还是圆，距离数值完全不变。

所以结论是：**L1 对特征的选取（坐标系）很敏感，L2 不会。** 如果我们的特征非常具体、有意义，并且我们希望保留这些信息，那么 L1 往往更好；如果特征比较随意，L2 距离就更合理。
课程还指出：用 L1 时，决策边界大部分都平行于特征轴 $`x_1`$、$`x_2`$，对特征非常敏感；而 L2 的边界会更复杂、更平滑。课程网站上有一个在线工具，可以切换不同的距离函数和不同的 $`k`$ 值，观察空间划分的变化。

## 九、超参数调优与数据集划分

### 9.1 什么是超参数

**超参数（hyperparameter）** 是那些你必须先做出选择、算法才能跑起来的变量。在 kNN 里有两个：

1. **k 的值**：取多少个最近邻，输出的结果就会不一样；
2. **距离函数**：L1、L2 还是别的。

超参数的选择往往**高度依赖于数据集**，有时也取决于具体问题。正因为有这种依赖，我们必须有办法把它们识别出来并加以优化——在机器学习、深度学习里，这通常就叫**超参数调优（hyperparameter tuning）**。

### 9.2 三种做法：只有第一个是对的

下表回答的是：**调超参数有哪些做法、为什么前两种是错的？**

| 做法 | 评价 | 原因 |
| --- | --- | --- |
| ① 挑在**训练集**上表现最好的超参数 | ❌ 坏主意 | 对 kNN 而言 $`k=1`$ 永远最佳——因为模型记住了训练数据，训练集准确率恒为 100%，完全没有参考价值 |
| ② 挑在**测试集**上表现最好的超参数 | ❌ 坏主意（近乎作弊） | 你在专门针对测试数据找最佳超参数，无法知道模型在测试集以外数据上的表现，也就无法估计泛化能力 |
| ③ 从训练集中划出**验证集**来调 | ✅ 正确做法 | 训练集只用来训练，验证集用来寻找/优化超参数，测试集只在最后用一次 |

关于做法 ②，课程反复强调：**绝对不要这样做**。测试集是一种非常宝贵的资源，理想情况下直到最后才碰一次；用它调参等于把测试集当成了训练集，得到的性能会过于乐观。

### 9.3 训练 / 验证 / 测试的标准划分

标准流程是：

1. 拿一部分训练数据作为**验证集（validation set）**，剩下的作为**训练集（training set）**；
2. 在训练集上训练模型；
3. 在验证集上寻找或优化超参数；
4. 找到最佳超参数组合后，再用它们在**测试集（test set）**上输出并汇报结果。

这个方法好得多，但它本身也有挑战：验证集通常要小得多，有时所选的验证集未必能很好地代表整体情况。

### 9.4 k 折交叉验证

更好的做法是采用**交叉验证（cross-validation）**来调超参数：

1. 把训练数据分成若干份（如 5 份）；
2. 每一份轮流充当验证集，其余用于训练，循环跑 5 次，即 **5 折交叉验证**；
3. 对给定的一个超参数取值，在 5 组数据上都跑一遍，算出验证集上的准确率，然后取平均；
4. 多试几次就能找到超参数的最佳配置；
5. 选好超参数后，再把它用到测试集上。

下表回答的是：**单验证集和 k 折交叉验证该怎么选？**

| 方案 | 优点 | 缺点 / 适用场景 |
| --- | --- | --- |
| 单一验证集 | 便宜、快 | 估计噪声大；深度学习大规模场景下常用 |
| k 折交叉验证 | 更可靠、效果更好 | 计算代价高；在大规模深度学习中使用较少，因为用大数据集反复训练非常困难 |

课程补充：在大规模深度学习中，人们常靠直觉调超参数，有时就用单一验证集；这套「主要用单验证集」的建议主要适用于非计算机视觉、非大规模数据集的场景。而学术论文通常要求做这类交叉验证和统计框架，以保证测试集上的结果能够**复现**。

## 十、kNN 在 CIFAR-10 上的真实表现

### 10.1 CIFAR-10 数据集

课程介绍了 **CIFAR-10** 数据集（做作业时经常用到）：它分为 10 类，包含若干训练图像和测试图像，图像尺寸为 $`32 \times 32 \times 3`$。

### 10.2 用五折交叉验证选 k

对每张测试图像运行最近邻算法，可以选出前 10 个最近邻并可视化出来。接下来的问题是：$`k`$ 该设成多少？课程用**五折交叉验证**做了一个快速实验——每个点对应一个 $`k`$ 值在五次折中的某一次结果。

- 结果：**k = 7 时效果最好，准确率接近 28%–29%**。
- 这个数字其实不错：因为这是一个**十类**分类问题，随机瞎猜只能得到 10% 的准确率，所以 kNN 确实在起作用。
- 但仍有很大的改进空间。

> 注：课程讲义（历史版本）中给出的是最近邻在 CIFAR-10 上约 38.6%（L1）/ 35.4%（L2）。本讲口述的是 $`k=7`$ 时约 28%–29%，本文以本讲视频为准。

### 10.3 为什么 kNN 在图像上注定失败

回看可视化结果能发现不少错误，尤其是离目标最近的那个样本往往是错的。例如：有的行里明明是只青蛙，第一个最近邻却看着像猫而不是狗。原因不难猜——**因为算距离用的是像素**：两张图的整体颜色分布差不多，大部分像素颜色接近，算出来的 L1/L2 距离就更近，但它们在语义上毫无关系。这说明：**基于像素值来算距离并不是好选择。**
最后一个例子更有说服力：看三张图，它们在颜色或遮挡上看起来差别很大，但实际上其中一张只是原图**往右平移了一个像素**。人眼看着毫无区别，但在算法里，它与原图的距离和其他两个「看起来完全不同」的例子是一样的。

## 十一、线性分类器

### 11.1 参数化方法：从「记住数据」到「学习参数」

线性分类器与最近邻的第一个根本区别：**这是一种参数化方法（parametric approach）**。意思是我们要去学习、去找到一组参数 $`W`$（权重），把输入图像映射出去、映射到输出类别的得分上。
下表回答的是：**kNN 与线性分类器的本质差异是什么？**

| 对比项 | kNN（非参数） | 线性分类器（参数化） |
| --- | --- | --- |
| 训练时做什么 | 记住全部训练数据 | 学习一组参数 $`W, b`$ |
| 测试时做什么 | 与所有训练样本比距离 | 一次矩阵乘法加偏置 |
| 训练后能否丢弃训练集 | 不能 | 可以，只留参数 |
| 测试代价 | $`O(N)`$，高 | 极低 |

### 11.2 评分函数与维度分析

我们搭建的这套方法，输出往往是「图像对那 10 个类别中每一个的置信度得分」。用这些参数把每个输入 $`x`$ 映射成一个输出 $`y`$，实现方式非常简单：

- 图像是 $`32 \times 32 \times 3`$ 的张量，也就是 **3072 个数值**，拉直后构成输入 $`x \in \mathbb{R}^{3072 \times 1}`$；
- 有 10 个输出类别，需要 10 个不同的得分，输出是 $`10 \times 1`$ 的向量；
- 因此要确定的权重矩阵 $`W`$ 大小为 $`10 \times 3072`$。

为了完善这个线性函数，通常还会加上**偏置（bias）** $`b`$，它是一个与输入无关的常数项。偏置的作用是让不同类别的分数整体产生偏移，从而更好地把各个类别分开。
线性分类器的**评分函数**：

```math
f(x, W) = Wx + b
```

课程反复强调：这些线性函数是搭建神经网络的基础模块。把线性分类器（线性函数）一个接一个拼起来，就构成了大型神经网络——虽然中间还得加不少东西（非线性等），但它确实是最核心的组件之一。观察流行的神经网络架构，你会发现线性函数无处不在。

### 11.3 代数视角

为了直观理解，课程把问题简化：不再用 $`32 \times 32`$ 的大图，而是看 **2×2 的图像**（只有四个像素）。输入图像被拉成向量，我们要找到 $`W`$ 和 $`b`$ 的值，把输入图像映射成输出分数。
下表回答的是：**线性分类器的三种理解视角分别是什么？**

| 视角 | 把 $`W`$ 的什么看作什么 | 直观含义 |
| --- | --- | --- |
| 代数视角 | $`Wx + b`$ 的一次矩阵运算 | 把图像向量映射成各类别分数（如猫、狗、船三类） |
| 模板视角 | $`W`$ 的**每一行**是一张类模板 | 模板匹配：用内积比较图像与哪类模板最像 |
| 几何视角 | $`W`$ 的每一行是一条决策边界 | 二维里是直线，高维里是超平面 |

### 11.4 模板视角

从视觉角度看：针对每个类别，我们定义了矩阵 $`W`$ 的一行，这一行就是该类别的**模板（template / prototype）**。把图像分别乘以对应猫、狗、船三个类别的模板 $`W`$ 并加上 $`b`$，就得到各类分数。
在 CIFAR-10 上训练好模型之后，从线性分类器的视觉角度可以观察到学到的 10 个类别模板。有意思的是：在某些情况下（比如汽车这个类），你确实能看到一个类似车头的模板——尽管这只用了一个线性分类器。
换个角度看模板视角：我们其实仍在做「最近邻」，只不过不再用成千上万张训练图像，而是**每个类只用一张图**（而且是学出来的，不必是训练集里的真实图像），并且用（负）内积代替 L1/L2 距离。这也解释了线性分类器的一个固有弱点：如果数据集中同一类有多种模态（比如朝左和朝右的马），线性分类器只能把这些模态**合并成一个模板**。

### 11.5 几何视角与偏置的作用

线性分类器常做的是找到那些把各个类别分开的线：

- 在二维空间里就是**直线**，把红、蓝、绿各类分开；
- 在更高维空间里，这些线变成了**超平面（hyperplane）**。

**偏置在这里非常有用**：没有它，所有直线/超平面都必须过原点（因为 $`x=0`$ 时得分恒为 0），这不合逻辑；有了偏置，我们就能建立更靠谱的函数和决策边界。

### 11.6 偏置技巧

同时维护 $`W`$ 和 $`b`$ 两套参数在推导和实现上都比较繁琐，因此有一个常用的化简技巧（课程讲义补充）：给输入向量 $`x_i`$ 额外补一维**恒为 1 的「偏置维度」**，同时给 $`W`$ 增加一列，这样评分函数就简化为单次矩阵乘法：

```math
f(x_i, W) = W x_i
```

以 CIFAR-10 为例：$`x_i`$ 从 $`3072 \times 1`$ 变成 $`3073 \times 1`$（多出的那一维恒为 1），$`W`$ 从 $`10 \times 3072`$ 变成 $`10 \times 3073`$，其中多出来的那一列就是偏置 $`b`$。

### 11.7 线性分类器做不到的事

线性函数和线性分类器在很多场景下都很有用，是搭建更复杂神经网络的基础模块，但它也有明确局限——**有些分布没法用一条直线分开**：

- **多象限情形**：第一类样本落在第一和第三象限，第二类落在第二和第四象限，任何一条直线都无法分开；
- **环形情形**：第一类是「到原点距离在 1 到 2 之间」的圆环区域，其余全归为第二类；
- **多块区域情形**：空间里有三块区域属于第一类，其余都算第二类。

在这些情况下都很难做线性划分，需要引入非线性（也就是后续课程要讲的内容）。

## 十二、损失函数与最优化的引入

### 12.1 为什么必须定义损失函数

我们已经看到线性分类器如何把输入图像映射成各类别得分，输出标签。现在的关键问题是：**怎么选对权重**：$`W`$，让每张图都能算出对应每个类别的合适得分？
为此需要定一个**损失函数（loss function）**，有时也称为**目标函数（objective）**或代价函数：它衡量分类器（模型）表现有多差，也就是相对于训练数据得分的不满意度。定义好之后，我们要找办法高效地调整 $`W`$ 的值，最小化这种不满意度，也就是最小化损失函数——**这就是优化过程**。

### 12.2 Softmax：把无界分数变成概率

以三分类（猫、汽车、青蛙）为例，线性函数给出的分数是 $`3.2`$、$`5.1`$、$`-1.7`$，也就是 $`f(x_i, W)`$ 的输出。
之所以要转换这些分数，是因为**它们没有上下界、数值往往很难控制**——毕竟这只是一个线性函数。最好的办法是把它们转化成概率，从而定义出「输入 $`x_i`$ 属于类别 $`k`$ 的概率」。
**Softmax 函数**分两步：

1. 对得分值做指数运算 $`\exp`$，输出值就总是正的（保证概率为正）；
2. 再做归一化，除以所有类别指数值之和。

```math
P(y = k \mid x_i; W) = \frac{e^{f_k}}{\sum_j e^{f_j}}
```

这样得到的数值总和为 1，构成了一个合法的概率分布函数。把 $`[3.2,\ 5.1,\ -1.7]`$ 代入：
下表回答的是：**线性层的原始分数经过 softmax 后变成了什么？（三分类示例：猫 / 汽车 / 青蛙）**

| 类别 | 原始分数 $`f`$ | $`e^{f}`$ | softmax 概率 |
| --- | --- | --- | --- |
| 猫 | 3.2 | 24.53 | 0.130 |
| 汽车 | 5.1 | 164.02 | 0.869 |
| 青蛙 | -1.7 | 0.18 | 0.001 |
| 合计 | — | 188.73 | 1.000 |

也就是说，这组 $`W`$ 判断这张图是猫的概率是 13%（0.13）。显然在这个例子里它出错了——因为权重 $`W`$ 设置得并不好，我们的优化过程就是要去调整它。
这些未归一化的对数概率（softmax 之前的分数）就是常说的 **logits**。这套框架其实和逻辑回归完全一样，只是因为这里有多个类别，所以叫**多分类逻辑回归（Multinomial Logistic Regression）**。

### 12.3 负对数似然损失

我们的目标是**最大化样本属于正确类别的概率**（上例中就是要最大化 0.13）。
但机器学习里的所有目标通常都写成**最小化**问题，所以做两步转换：

1. 取负：最大化问题变成最小化问题；
2. 取对数：让数值更好处理（把连乘变成连加，单调且数值稳定）。

于是损失函数定义为**正确类别概率的负对数**：

```math
L_i = -\log\left(\frac{e^{f_{y_i}}}{\sum_j e^{f_j}}\right) = -f_{y_i} + \log\sum_j e^{f_j}
```

上例中 $`L_i = -\log(0.13) \approx 2.04`$。如果你上过 CS229 这类课，会知道它常被称为**最大似然估计（MLE, Maximum Likelihood Estimation）**——本质上是同一个算法。

### 12.4 信息论视角：交叉熵与 KL 散度

换个思路还能得到同一个损失函数。假设我们有估计出来的概率分布 $`q`$，以及定义正确概率的分布 $`p`$（正确类别上为 1、其余为 0 的 one-hot 分布），我们要做的就是**让这两个概率分布匹配起来**。为此要最小化 **KL 散度（Kullback-Leibler Divergence）**：

```math
D_{\mathrm{KL}}(p \| q) = - \sum_x p(x) \log q(x) + \underbrace{\sum_x p(x)\log p(x)}_{\text{熵 } H(p)}
```

而在本设定下，KL 散度就简化成了前面定义的负对数函数。再深入一点，这其实正是**交叉熵（cross-entropy）**：

```math
H(p, q) = -\sum_x p(x)\log q(x) = H(p) + D_{\mathrm{KL}}(p \| q)
```

因为正确标签采用**独热（one-hot）编码**时，真实分布的熵 $`H(p) = 0`$，所以交叉熵就退化成了同样的负对数似然函数。这也是我们把这个函数叫做交叉熵（或二元交叉熵）的原因之一——在深度学习中，只要你用过深度网络框架，肯定听过 **BCE（Binary Cross-Entropy）**。

### 12.5 两个课堂提问：取值范围与初始值

**问题 1**：$`L_i`$ 的最小值和最大值分别是多少？

- 当正确类别概率趋近 1 时，$`\log(1) = 0`$，$`L_i \to 0`$，这是最小值；
- 当正确类别概率趋近 0 时，$`\log \to -\infty`$，取负后 $`L_i \to +\infty`$，没有有限的最大值。

**问题 2**：初始化时 $`W`$ 近乎随机、各类别概率大致相等，损失是多少？
假设有 $`C`$ 个类别，每个类别概率约为 $`1/C`$，则

```math
L_i = -\log(1/C) = \log C
```

若有 $`C = 10`$ 个类别，$`\ln 10 \approx 2.3`$（注意这里是**自然对数** $`\ln`$）。这是一个非常好用的 sanity check：训练刚开始时，交叉熵损失应该在 $`\ln C`$ 附近；如果差得远，说明实现有 bug。

### 12.6 最优化：留到下一讲

至此我们完成了两件事：

1. 定义了损失函数——正确类别概率的负对数，概率则由 softmax 给出；
2. 知道了要「让它变好」。

**接下来优化它、真正找到正确的 W，是下一讲的主题。** 至于另一种常用的多类损失（多类 SVM / 合页损失 hinge loss），本讲并未展开，留待后续课程与作业。
